마이김변 카드뉴스 콘텐츠 작성 브리프 (Instagram/Facebook 캐러셀, 1080x1350)

■ 목적
개인회생·개인파산·채무조정 정보를 정확하고 쉽게 알리고, 마지막 장(자동 생성 CTA)에서 마이김변(my김변, mykim.kr)을 자연스럽게 홍보한다.
독자: 빚 때문에 불안한 20~60대. 저장·공유하고 싶은 실용 정보가 핵심.

■ 파일 형식
scripts/cardnews/content/partN.mjs 에 `export default [ ...포스트 ]`. 예시·품질 기준은 part1.mjs 의 id 1~5 를 그대로 참고한다.

슬라이드 타입 (필드):
- text {kicker?, title, body: string|string[], note?}
- list {title, items:[{t, d?, icon?}] 2~5개, note?}   (icon 없으면 번호)
- check {title, items: [string | {t,d?}] 2~6개, note?}
- steps {title, steps:[{t,d?}] 2~5개, note?}
- ox {title?, items:[{q, a:'O'|'X', d}] 1~3개}   (1개면 크게 표시)
- compare {title, cols:[A이름,B이름], rows:[[행라벨, A, B]] 2~6행, note?}   (셀은 짧게 12자 안팎)
- qa {q, a: string|string[], note?}
- chat {title?, header:'문자 메시지' 등, msgs:[{from:'l'|'r', name?, text}] 2~5개, note?}  (자동으로 '이해를 돕기 위한 예시' 표시)
- stat {kicker?, big:'짧은 숫자/단어', unit?, title, body, note?}   (big 은 법령·제도상 확실한 숫자만)
- tip {label?, title?, body, icon?, note?}
- warn {label?, title?, items:[string] 또는 body}
- glossary {title, terms:[{t, d}] 2~5개}
- quote {text, by?}   (자동으로 '가상 예시' 표시. 실존 인물·실제 후기처럼 쓰지 말 것)
텍스트 마크업: **강조**(포인트 색), ==형광펜==, \n 줄바꿈. 한 장에 강조는 1~2곳만.

■ 디자인 다양성 규칙
- 한 파트 안에서 theme 은 8종을 고르게, 연속한 두 포스트가 같은 theme 금지. 경고·주의 주제는 coral/dark, 신뢰·기초는 navy/white/sky, 체크리스트는 memo/cream 이 어울림.
- cover.style 5종을 고르게 섞는다(각 3~5회). 연속 같은 style 금지.
- 한 포스트 안에 최소 3가지 다른 슬라이드 타입. 같은 타입 2장 연속은 최대 1번(ox 1개씩 연속 배치는 허용).
- 파트 전체에서 모든 타입을 최소 2번씩 사용.
- 슬라이드 분량: list/steps 항목 d 는 40자 이내, body 문단은 2개·각 90자 이내. 넘치면 자동 축소되니 짧고 굵게.

■ 카피 원칙 (변호사 광고 규정 · 프로젝트 규칙, 위반 시 검사기에서 차단)
금지: 무료 상담 / 100% ·무조건·반드시·확실히 + 탕감·면책·인가 / 탕감·면책 보장 / 성공률·인가율·면책률·탕감률 / 국내 최초·유일·최고·1위 / 회생·파산 전문 변호사 / 역경매·최저가·수임료 할인 / 기적·획기적·빚 0원·인생 역전 / 실제 사례·실제 후기·OO씨 사례 / 변호사 소개·알선·연결해 드림·맞춤 매칭 / 유출 0%·완벽 차단·절대 노출 안 됨 / 근거 없는 % 통계.
대신: "법원이 요건을 보고 판단합니다", "사건마다 다를 수 있습니다", "변호사 정보를 확인하고 직접 선택".
문체: 평이한 존댓말(~입니다/~해요 중 한 포스트 안에서 통일), 따뜻하지만 과장 없이. 공포 마케팅 금지. 짧은 문장.
결과 판단 주체는 항상 법원. 개별 사안 판단은 "선택한 변호사와 확인".

■ 마이김변 사실 (이 범위 밖의 기능을 지어내지 말 것)
- 리걸테크 플랫폼. 상담·수임은 의뢰인이 선택한 법률사무소가 수행. 인가·면책은 법원 판단.
- 스텔스 가명으로 상담 요청, 010 번호 없이 시작, 실명·연락처는 계약 전까지 변호사에게 공개되지 않음. ('100% 익명', '스텔스 가명', '스텔스 보증'은 공식 용어로 사용 가능)
- 변호사 프로필을 먼저 보고 최대 3명까지 골라 한 번에 상담 요청, 답변·프로필 비교, 원할 때만 진행(선임 강요 없음).
- 익명 채무 체크(mykim.kr/check): 채무 상황 정리, 회생·파산·채무조정 등 4가지 해결 경로 비교. 결과는 참고용.
- AI 음성 진술서: 사정을 말로 설명하면 진술서 초안 작성 보조. 직접 수정 가능, 최종 검토는 선택한 변호사.
- 서류 허브: 제출 서류를 한곳에 정리.
- 상담방에서 편한 시간에 대화, 모바일 전자서명 계약, 계약서 전자지문(해시)으로 원본 확인. 사건에 따라 방문 필요할 수 있음.
- 회생동행 캘린더: 다음 변제일까지 남은 날 표시, 납부일이 지나도 기록이 없으면 미납 경고, 회차별 납부 기록.
- 상담 요청 단계 플랫폼 이용료 0원. 수임료 분납 가능 변호사 필터. 수임료 금액·분납은 법률사무소와 직접 협의.
- SSL/TLS 암호화 전송·서버 암호화 저장.

■ 품질 기준
- 표지 제목은 궁금증·공감형 훅(질문, 오해, 숫자, 상황 묘사). 뉴스 헤드라인처럼 구체적으로.

- 주제별로 실제로 도움이 되는 구체 정보(어디서, 언제까지, 무엇을)를 담는다.
