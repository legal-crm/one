- **인증서 금고:** 제로날리지를 유지한 채 서버에 저장해요. 의뢰인 브라우저에서 PIN으로 암호화한 **암호문만** 서버에 올리고, 복호화는 PIN을 아는 사람의 브라우저에서만 해요. 서버·운영자는 열 수 없어요. 사무소가 열람할 때 PIN을 어떻게 전달받는지(의뢰인 승인 흐름)는 설계 단계에서 정해요.

- **완료 기준:** 코드 검색에서 위 데이터의 localStorage 단독 저장이 0건이고, 두 기기(사무실 PC·의뢰인 휴대폰, 대표·직원 계정)에서 같은 데이터가 보여요.
