## 1. 출시 목표와 범위

### 1-1. 서비스 정의
개인회생·파산 상담자가 **스텔스 가명**으로 채무 정보를 정리하고, 상담받을 변호사를 **직접 선택**하는 채무상담 플랫폼 + 변호사 사무소용 회생·파산 실무 CRM.

### 1-2. 출시 원칙 (확정)
| 원칙 | 내용 |
|:---|:---|
| 변호사법 | 매칭·배정·추천·공개 요청 없음. 수익은 정액 광고비뿐. 상담·수임 연동 과금 없음 |
| 의뢰인 화면 | 예상 월 변제금·감면율 비노출. 예외: 변호사가 보낸 보고서·제안서, **제도 이해용 계산기**(공개 기준 일반 계산, 범위 표시, 감면율·가능성 표현 없음, 저장 안 함 — 10-24 결정, 외부 변호사 검토 대상). 계산기는 **홈 3번 섹션(1분 빠른 모드)·검색용 `/calculator` 페이지**로 첫 방문 유입 장치로 씀 |
| 데이터 | 업무 데이터는 전부 서버 저장. 관리자는 의뢰인 서류·상담 원문 열람 불가 |

## 3. 출시 판정 기준 (Go / No-Go)

### 3-1. 비공개 베타 진입 조건 (단계 4 → 5)
- [ ] 체크리스트 재판정 완료, 미완 항목이 모두 분류됨 (A-1)
- [ ] 계산 엔진: 실제 접수 4건을 원 단위까지 재현 (B-2)
- [ ] 의뢰인 화면에 변제금·감면율 노출 0건 (B-4)
- [ ] 공개 요청·영업 DB 수당 코드 0건 (A-6)
- [ ] 금지어(전담·매칭·배정·추천·입찰) 노출 0건
- [ ] 서버 저장 전환 완료, 두 기기 동기화 확인 (S)
- [ ] 마이그레이션 전체 실행·검증, RLS 교차 접근 시험 통과 (A-1 G1)
- [ ] E2E: 고객 체크 → 변호사 선택 → 동의 → 제안 → 상담 → 원격 계약 → 서류 제출 → 사건 진행 (C-3)
- [ ] 개인정보 처리방침·약관 개정본 게시 (4-2)

### 3-2. 정식 오픈 조건 (단계 5 → 6)
- [ ] 베타 중 발견된 심각(데이터 유실·권한 노출·계약 오류) 결함 0건
- [ ] KG이니시스 통합인증 실연동 완료: 포트원 실연동 채널·`PORTONE_API_SECRET` 등록, PC·안드로이드·아이폰 실제 인증 성공, 이니시스에 연동 완료 회신 (개발 A-7)
- [ ] 운영 환경변수 전부 등록: 팝빌, Turnstile, Gmail SMTP, CODEF(또는 해당 기능을 '준비 중'으로 숨김)
- [ ] 알림톡 승인 템플릿 확보 (최소: 상담 접수, 제안서 도착, 계약 요청, 서류 요청, 분납 안내, 보정 마감)
- [ ] 서버 백업 정기 실행·복원 시험 1회 성공 (G-2)
- [ ] 오류 모니터링·가동 감시 동작 (5-3)
- [ ] 법률 검토 완료 (약관·처리방침·광고 상품·가입 안내 문구) (L4)
- [ ] 사업자 정보·고객센터 정보 확정 및 표시 (L2·L3)
- [ ] Vercel·Supabase 유료 플랜 전환 (상업 이용 조건) (6장)
- [ ] 승인 변호사 수 목표 달성 (L1에서 정할 숫자)

### 3-3. 출시 중단·롤백 기준
- 개인정보 노출(다른 사람 데이터가 보임), 계약서 무결성 오류, 결제·세금계산서 오발행 → 즉시 해당 기능 차단 + 직전 배포로 되돌림
- 되돌리기 방법: Vercel 이전 배포로 즉시 전환(Instant Rollback), DB는 G-2 백업 기준

### 10-2. AI 사건 분석 과금 모드 (LA-Q1 설계)

- **지금 (출시):** 모드 = '무료(전체 개방)'. 모든 승인 변호사가 사용, 사이드바 '유료' 배지·잠금 제거.
- **나중에 바꿀 수 있게 만드는 것**
  1. **통합어드민 플랫폼 설정 > 부가 기능 과금:** 기능별 모드 선택 — ① 무료(전체) ② 광고 구매 변호사 혜택 ③ 유료(정액 월 이용료). 정액 금액·전환 예정일 입력.
  2. **변호사별 예외:** 기존 `aiCaseAnalysisEnabled`(변호사별 켜기)를 '모드와 무관하게 허용/차단'하는 예외 설정으로 유지 (베타 변호사 무상 제공 등).
  3. **전환 절차:** 전환 예정일을 넣으면 그날 **30일 전**에 변호사 어드민 공지·알림으로 자동 안내, 전환일에 모드 적용. 진행 중인 보고서·이미 보낸 보고서는 유료 전환 후에도 계속 열람 가능.
  4. **유료 결제:** 광고 상품과 같은 흐름 재사용 — 변호사 어드민 '광고·결제'에 '부가 서비스' 상품으로 신청 → 계좌 입금 → 관리자 확인 → 세금계산서 → 이용 기간 동안 사용. 별도 결제 시스템을 새로 만들지 않아요.
  5. **문구 연동:** 가입 안내·비용 카드·이용가이드의 "CRM 이용료 0원" 등 문구를 모드에 따라 자동으로 바꿔요(무료 모드 = 지금 문구, 유료 모드 = "기본 CRM 무료, AI 사건 분석은 월 ○원").
  6. **약관:** 변호사 회원 약관에 "부가 기능은 사전 고지 후 유료로 전환될 수 있음" 조항.
- **변호사법 원칙:** 유료라도 **정액**만. 상담 건수·수임 건수·수임료와 연동한 과금은 설정에서 고를 수 없게 해요.
- **확장:** 같은 설정 구조를 다른 부가 기능(예: HWPX 일괄 출력, 예약 발송)에도 쓸 수 있게 기능 목록 형태로 만들어요.
