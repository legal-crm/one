## 1. 출시 목표와 범위

### 1-1. 서비스 정의
개인회생·파산 상담자가 **스텔스 가명**으로 채무 정보를 정리하고, 상담받을 변호사를 **직접 선택**하는 채무상담 플랫폼 + 변호사 사무소용 회생·파산 실무 CRM.

### 1-2. 출시 원칙 (확정)
| 원칙 | 내용 |
|:---|:---|
| 변호사법 | 매칭·배정·추천·공개 요청 없음. 수익은 정액 광고비뿐. 상담·수임 연동 과금 없음 |
| 의뢰인 화면 | 예상 월 변제금·감면율 비노출. 변호사가 보낸 보고서·제안서 수치만 예외 |
| 데이터 | 업무 데이터는 전부 서버 저장. 관리자는 의뢰인 서류·상담 원문 열람 불가 |

| 변호사 | 실제 가입·승인한 변호사만 노출 |

| 구분 | 출시 때 포함 | 출시 후 |

## 3. 출시 판정 기준 (Go / No-Go)

### 3-1. 비공개 베타 진입 조건 (단계 4 → 5)
- [ ] 체크리스트 재판정 완료, 미완 항목이 모두 분류됨 (A-1)
- [ ] 계산 엔진: 실제 접수 4건을 원 단위까지 재현 (B-2)
- [ ] 의뢰인 화면에 변제금·감면율 노출 0건 (B-4)
- [ ] 공개 요청·영업 DB 수당 코드 0건 (A-6)
- [ ] 금지어(전담·매칭·배정·추천·입찰) 노출 0건
- [ ] 서버 저장 전환 완료, 두 기기 동기화 확인 (S)
- [ ] 마이그레이션 전체 실행·검증, RLS 교차 접근 시험 통과 (A-1 G1)
- [ ] E2E: 고객 체크 → 변호사 선택 → 동의 → 제안 → 상담 → 원격 계약 → 서류 제출 → 사건 진행 (C-3)
- [ ] 개인정보 처리방침·약관 개정본 게시 (4-2)

### 3-2. 정식 오픈 조건 (단계 5 → 6)
- [ ] 베타 중 발견된 심각(데이터 유실·권한 노출·계약 오류) 결함 0건
- [ ] 운영 환경변수 전부 등록: PortOne, 팝빌, Turnstile, Gmail SMTP, CODEF(또는 해당 기능을 '준비 중'으로 숨김)
- [ ] 알림톡 승인 템플릿 확보 (최소: 상담 접수, 제안서 도착, 계약 요청, 서류 요청, 분납 안내, 보정 마감)
- [ ] 서버 백업 정기 실행·복원 시험 1회 성공 (G-2)
- [ ] 오류 모니터링·가동 감시 동작 (5-3)
- [ ] 법률 검토 완료 (약관·처리방침·광고 상품·가입 안내 문구) (L4)
- [ ] 사업자 정보·고객센터 정보 확정 및 표시 (L2·L3)
- [ ] Vercel·Supabase 유료 플랜 전환 (상업 이용 조건) (6장)
- [ ] 승인 변호사 수 목표 달성 (L1에서 정할 숫자)

### 3-3. 출시 중단·롤백 기준
- 개인정보 노출(다른 사람 데이터가 보임), 계약서 무결성 오류, 결제·세금계산서 오발행 → 즉시 해당 기능 차단 + 직전 배포로 되돌림
- 되돌리기 방법: Vercel 이전 배포로 즉시 전환(Instant Rollback), DB는 G-2 백업 기준
