## 1. Part 3 방향

참조 채널(회생·파산 사건을 다루는 법무사·변호사 쇼츠 16편)은 "한 가지 궁금증 → 핵심 정보 2~4개 → 상담 권유" 구조로 시청 유지율을 확보한다.
Part 3은 이 **정보 전달 구조만 참고**하고, 대본과 화면은 마이김변 톤으로 새로 작성했다. 참조 영상의 문장·장면·출연자는 쓰지 않는다.

| 항목 | 참조 쇼츠 | 마이김변 Part 3 |
|---|---|---|
| 화면 | 출연자 토킹헤드 | 모션 그래픽·예시 UI (실존 인물 없음) |
| 정보 | 실무 경험 위주 설명 | 같은 주제를 법 조항·실무 기준과 유의 문구로 정리 |
| 마무리 | 사무소 상담 권유 | 엔드카드: 마이김변 로고 + "프로필 링크 → 익명 채무 체크" + 고지문 |
| 기능 연결 | 없음 | 익명 채무 체크·가명 상담방·DocHub·변호사 직접 선택 |

주의해서 바꾼 표현
- "딱 한 번뿐" → "한 번뿐일 수 있는 기회" (단정 회피)
- "두 배로 갚는다" → "돈이 두 번 나가는 셈이 될 수 있다"
- 통계·증가율 언급(신청자 급증, 역대 최고치 등) → 출처 없는 수치라 사용하지 않음, "예시 상황" 표기
- 연도별로 바뀌는 금액(생계비 기준, 지역별 주거비 상한) → 금액 없이 구조만 설명, "기준은 바뀔 수 있음" 표기
- 수치는 법 조항에 있는 것만 사용 (채무 한도 10억·15억, 면책 이력 5년, 변제기간 원칙 3년·최장 5년)

## 3. 공통 제작 규격 (Part 1·2 규격 + Part 3 추가 요소)

| 항목 | 규격 |
|---|---|
| 해상도·길이 | 1080×1920, 30fps, 편당 약 34~50초, 장면 5~6개 |
| 구조 | 훅 질문 → 정보 2~4개 → (기능 데모) → 엔드카드 |
| 자막 | 줄당 8자 이내·2줄, 핵심어 1개 Teal 하이라이트, 좌측 정렬(우측 15%·하단 20% 세이프존 회피) |
| 시리즈 칩 | 좌상단 "회생 노트 N" (엔드카드 제외) |
| 진행 바 | 화면 최상단 Teal 진행 바 (시청 유지 장치) |
| 전환 | 장면 전환 시 펀치 줌 + whoosh 효과음 |
| 효과음 | 코드로 합성한 pop·tick·thump·ding·alert (저작권 이슈 없음), 내레이션 키워드 시점에 싱크 |
| 근거 표기 | 법 조항·실무 기준 언급 장면은 하단 세이프존 위에 근거·유의 문구 |
| 엔드카드 | 로고(이 장면에만) + 캡션 + "프로필 링크 → 익명 채무 체크" + 짧은 고지문 |
| 내레이션 | edge-tts `ko-KR-SunHiNeural`, 숫자·영문은 TTS용 한글 표기로 별도 입력 (예: 독허브, 오 년) |
