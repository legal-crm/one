# 마이김변 법률 검토 결과 (R6)

- **검토 변호사:** 법률사무소 명율 소성록 변호사 (자문 조건: 마이김변에 광고하지 않음, 건수와 무관한 정액 자문)
- **검토 대상:** [00_review_request.md](00_review_request.md) 쟁점 1~39, [01_calculator_review.md](01_calculator_review.md) 검토 질문 1~8, 2026-11-01 개정 이용약관·변호사회원 이용약관·개인정보 처리방침·법적 고지
- **결과 (2026-11-01, 대표를 통해 전달):** 모두 **'그대로 진행'** 확인. 고친 문구 없음.
- **기록:** 운영 DB `legal_documents`의 2026-11-01 판 4개에 검토 변호사·검토일 저장(마이그레이션 `20261101004700_legal_review_r6`), 관리자 조치 기록에 '검토 반영' 한 줄.

## 반영한 것

| 쟁점 | 반영 |
|:---|:---|
| 계산기 1~8 (쟁점 8) | 통합어드민 기능 표시 '변제금 계산기 공개'를 켬 → 고객 화면 메뉴·홈 3번 구역·정리 확인 화면 버튼이 보이고, 다음 배포부터 `/calculator` 안내 페이지 검색 허용·사이트맵 등록. 화면 문구는 검토본 그대로 |
| 약관·처리방침·법적 고지·변호사 약관 (2장) | 2026-11-01 판을 확정본으로 둠. 새 버전 게시 없음. 의뢰인 다시 동의(이용약관·처리방침)는 이미 켜져 있음 |
| 쟁점 10 제도 안내 | 문구 그대로. 정적 페이지 `/guide/debt-programs`에 '법률 검토: 소성록 변호사(2026-11-01)' 표시 |
| 쟁점 11 제안서 FAQ·용어집 | 문구 그대로("일반적으로 … 사건마다 다를 수 있어요" 유지) |
| 쟁점 17 보유 기간·휴면 분리 | 그대로 (휴면 분리 보관 안 함) |
| 쟁점 22 첫 연락 알림톡 고지 한 줄 | 카카오 템플릿 승인 뒤 넣는 계획 그대로 |

| 쟁점 34·35 예시 사례·후기 | 그대로 (예시 표시·검색 제외, 실제 후기만 동의 기록 후 게시) |
| 쟁점 37~39 계산 기준 | 화면의 '확인 필요' 표시와 기준값 그대로 |

## 앞으로

- 약관·처리방침을 다시 고치면 새 판을 이 변호사에게 다시 보내고, 검토가 끝난 판에만 검토일을 적는다.
- 새 칼럼은 검토를 받은 글에만 검토자·검토일을 넣는다. 검토 전 글은 '마이김변 편집팀'만 표시한다.
