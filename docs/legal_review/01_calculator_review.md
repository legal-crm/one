# 제도 이해용 변제금 계산기 — 공개 전 검토 자료

- **받는 분:** 법률사무소 명율 소성록 변호사님
- **상태:** 구현은 끝났고 **고객 화면에서는 숨겨 둔 상태**입니다. 검토 의견을 반영한 뒤 통합어드민 '플랫폼 설정 › 기능 표시'에서 켜면 고객 화면에 나오고, 다음 배포부터 `/calculator` 안내 페이지가 검색에 나옵니다.
- **확인 방법:** 화면 확인이 필요하시면 시험 환경 주소와 화면 캡처를 따로 보내 드립니다.

## 1. 왜 만드나요

의뢰인은 상담 전에 "대략 얼마를 갚는지"를 가장 궁금해합니다. 플랫폼이 개별 사건을 판단해 숫자를 단정하면 변호사법 제109조 위험이 있습니다. 그래서 다음 원칙을 정했습니다(10-24 결정).

- **공개된 기준을 적용한 일반 계산**만 합니다(기준 중위소득 고시, 회생법원 실무준칙, 생계비 검토 위원회 의결, 민사집행법 시행령, 채무자회생법).
- 숫자 하나가 아니라 **범위**로 보여 줍니다. 범위의 양 끝은 추가 생계비를 법원이 인정하지 않을 때와 인정할 때입니다.
- **감면율·감면액, '가능/불가', '조정 가능성' 표현은 없습니다.**
- 입력값과 결과는 **저장하지 않고 서버로 보내지 않습니다**(브라우저 안에서만 계산). 결과를 상담 요청에 붙이지도 않습니다.
- 화면 아래에는 '내 상황 체크하기'와 '변호사 찾기' 일반 버튼만 둡니다. "이 결과로 상담 요청" 같은 연결 버튼은 없습니다.

## 2. 어디에 나오나요

| 위치 | 내용 |
|:---|:---|
| 홈 3번 구역 '1분이면 대략적인 변제금 범위를 볼 수 있어요' | 입력 4개(월 실수령 소득, 총 채무, 가구원 수, 주거 형태). 정보가 적어 범위가 넓습니다 |
| 홈 첫 화면 주 버튼 아래 | 보조 링크 "1분 변제금 계산해 보기 ↓" |
| 메뉴 '변제금 계산기(참고용)' | 전체 계산기 |
| '정리 확인' 화면 | '계산기로 직접 계산해 보기' 버튼. 의뢰인이 누를 때만 정리한 입력값을 불러오고 "정리한 내용에서 불러온 값이에요" 안내를 띄웁니다. 재산은 종류를 몰라 불러오지 않습니다 |
| `/calculator` 안내 페이지 | 계산 방법·근거·자주 묻는 질문 7개. 계산기를 켜기 전에는 검색 제외(noindex) |

## 3. 입력 항목 (전체 계산기)

- **소득과 채무:** 월 실수령 소득, 소득 형태(급여/영업/프리랜서·일용), 총 채무, 그중 세금·4대보험 체납, 적용 연도(2025~2027)
- **가족과 사는 곳:** 가구원 수, 미성년 자녀 수, 배우자 소득 여부, 사는 지역, 주거 형태, 월세, 보증금, 매달 의료비, 자녀 1명당 교육비
- **주요 재산:** 예금·적금, 보험 해약환급금 합계, 자동차(시세 − 할부 잔액), 부동산(시세 − 담보 대출)
- **변제기간에 영향을 주는 사정(선택):** 출생연도, 관할 법원(서울회생 / 수원·부산·대전·대구·광주회생 / 그 밖의 지방법원 / 모름), 장애의 정도가 심한 장애인, 한부모 가족, 전세사기피해자 결정. 서울회생법원을 고르면 취약채무자 요건 칸이 더 나옵니다.
  - 이 사정들은 화면에서만 쓰고 저장하지 않습니다.
  - 회생법원을 고르고 사정이 있으면 **짧은 기간을 범위의 낮은 쪽에만** 넣습니다. 높은 쪽은 3년 원칙입니다.
  - 지방법원이나 '모름'을 고르면 3년으로 계산하고 "관할 법원 기준 확인이 필요하다"고 안내합니다.

## 4. 계산 방법 (변호사 화면과 같은 엔진)

1. 기본 생계비 = 그해 기준 중위소득 60%(가구원 수별, 원 단위 반올림)
2. 추가 생계비 = 주거비·의료비·교육비 중 각 회생법원 생계비 검토 위원회 의결 한도 안 금액 → 범위의 낮은 쪽에만 넣습니다
3. 매달 갚을 수 있는 돈 = 소득 − 인정 생계비
4. 재산 가치(청산가치) = 예금·보험 해약환급금은 합쳐서 250만 원 공제, 보증금은 소액임차 공제
5. 변제기간 = 3년 원칙. 재산 가치나 우선 채무를 채우려면 최장 5년, 원금을 일찍 다 갚으면 그만큼 짧게
6. 결과 = 월 변제금·변제기간·총 변제액 범위(만 원 단위로 바깥쪽 반올림), '어떻게 계산했나요?' 펼치기(위 단계별 금액), '결과를 바꾸는 요인'(입력에 따라 고른 일반 안내), 근거(고시 번호·의결·실무준칙 조항)

- 같은 입력이면 변호사 '사건 검토'·변제계획 편집기·실무 퀵툴과 결과가 같도록 자동 시험으로 확인하고 있습니다.
- 실제 접수본 3건과 생계비가 원 단위로 같은 것도 확인했습니다.
- 채권자별 월 변제액은 원 미만을 올리므로, 법원 서식 합계는 계산기 값보다 몇 원 클 수 있습니다(C-1 결정).

## 5. 화면 문구 (그대로 옮김)

- **제목:** "공개 기준으로 보는 개인회생 변제금 범위"
- **설명:** "기준 중위소득 생계비·추가 생계비 기준·재산 가치·변제기간 원칙을 적용해 대략적인 범위를 보여 드려요. 내 사건에서 실제로 얼마를 갚게 되는지는 자료를 확인한 변호사와 법원이 정해요."
- **결과 머리:** "공개 기준 참고 범위 (2026년 기준표)"
- **결과 줄:** "월 변제금 약 ○만 원 ~ ○만 원", "변제기간 ○ ~ ○개월", "이 기간 동안 갚는 돈은 모두 약 ○만 원 ~ ○만 원이에요."
- **소득이 기본 생계비 이하일 때:** "이 경우 매달 갚을 돈이 계산되지 않아요. 개인회생 대신 개인파산 절차를 살펴볼 수 있는지는 변호사와 확인해 보세요."
- **재산 가치가 채무 이상일 때:** "이 경우 개인회생 계산 방식이 맞지 않을 수 있어요. 어떤 절차가 맞는지는 변호사와 확인해 보세요."
- **결과를 바꾸는 요인(예):**
  - "주거비·의료비·교육비를 생계비에 더 넣어 주는지는 관할 법원이 정해요. 그래서 범위로 보여 드려요."
  - "세금·4대보험 체납은 다른 채무보다 먼저, 보통 변제기간 절반 안에 갚아야 해요."
  - "입력한 사정(…)은 관할 회생법원 실무준칙의 3년 미만 변제기간 사유에 들어가요. 그래서 짧은 기간도 범위에 넣었어요. 실제로 줄일지는 변호사가 서류를 보고 검토해요."
- **하단 고지:** "공개된 기준을 적용한 참고용 일반 계산이며, 개인 사건의 결과를 판단하지 않습니다. 입력한 값은 저장하거나 보내지 않습니다."

## 6. 검토 질문

1. 이 구조(공개 기준 일반 계산, 범위 표시, 저장·전송 없음, 상담 연결 버튼 없음)로 의뢰인에게 월 변제금 범위를 보여 주는 것이 제109조의 법률 사무에 해당하지 않는지 봐 주세요.
2. 위험을 더 줄이려면 표시를 바꿔야 하는지 봐 주세요. 예: 총 변제액을 빼기, 범위를 더 넓히기, 결과 앞에 고지문을 한 번 더 넣기.
3. "개인파산 절차를 살펴볼 수 있는지 변호사와 확인해 보세요" 안내가 특정 제도를 권하는 것으로 보이지 않는지 봐 주세요.
4. 3년 미만 단축 사유를 입력받아 짧은 기간을 범위에 넣는 방식이 괜찮은지 봐 주세요. 장애 여부는 저장하지 않지만 민감정보 성격입니다.
5. 홈 배치(3번 구역과 첫 화면 보조 링크)가 상담 유도 광고로 보이지 않는지 봐 주세요.
6. '정리 확인' 화면에서 계산기를 여는 연결을 봐 주세요. 의뢰인이 직접 누를 때만 열고, 결과는 상담 요청에 붙이지 않습니다.
7. `/calculator` 안내 페이지의 설명과 자주 묻는 질문 7개가 정확한지 봐 주세요.
8. 고지문 문구를 고쳐야 하는지 봐 주세요.

## 7. 공개 순서 (검토가 끝나면)

1. 의견 반영(문구·표시 수정) → 자동 시험 통과 확인
2. 통합어드민 '플랫폼 설정 › 기능 표시'에서 '변제금 계산기 공개' 켜기 → 고객 화면 즉시 표시
3. 다음 배포 때 `/calculator` 검색 허용·사이트맵 등록(자동)
4. 검토 기록(검토일·검토 변호사)을 이 문서에 남김
