## 1. 조사·분석 요약

### 1-1. 서비스에서 확인한 사실 (영상에 쓸 수 있는 근거)

| 소구점 | 사이트 근거 | 영상에서 쓸 표현 |
|---|---|---|
| 익명 시작 | 실명·주민번호 없이 채무·소득 입력 | "이름 없이 1분이면 내 상황 정리" |
| 4가지 경로 | 회생·파산·신용회복·채무자대리 비교 | "개인회생이 정답이 아닐 수도 있습니다" |
| 스텔스 가명 | 계약 전까지 실명·연락처 비공개, 010 번호 비공개 | "010 번호를 공개하지 않고 상담 요청" |
| 직접 선택 | 최대 3명 선택 → 한 번에 요청 → 답변 비교, 선임 강요 없음 | "내가 고르고, 답변을 나란히 비교" |

| AI 음성 진술서·DocHub | 말로 설명하면 진술서 초안, 제출 서류 정리 | "말하면 진술서 초안이 만들어집니다" |
| 서류 호환 | 다른 사무소·나홀로 신청도 링크·QR 전달 | "어디서 진행하든 서류는 링크로" |
| 모바일 전자계약 | 방문 없이 계약, 계약서 해시 블록체인 기록 | "방문 없이 폰으로 계약" |
| 회생동행 캘린더 | 납부일 알림, 미납 경고 | "인가 후 변제기간, 납부일을 챙겨줍니다" |

### 1-2. 쇼츠 포맷 인사이트

- 길이: 15~30초 구간에서 시청 유지율이 가장 높다는 분석이 있음 ([Opus](https://www.opus.pro/blog/ideal-youtube-shorts-length-format-retention)). 내부 엔진 규격(30~38초)과 절충해 **편당 28~32초, 장면 5개**로 맞춤.
- 첫 3초가 배포를 가름: 초기 이탈이 크면 알고리즘이 노출을 줄임 ([vexub](https://vexub.com/blog/hook-formula), [opus.pro](http://opus.pro/blog/youtube-shorts-hook-formulas)). 인사말·로고 인트로 없이 **공감 질문 한 문장**으로 시작.
- 1차 성과 지표: 게시 24시간 동안 "시청 vs 스와이프" 70% 이상 ([shortgenius](https://shortgenius.com/blog/youtube-shorts-best-practices)).
- 2025년 3월부터 쇼츠 조회수는 재생·반복 재생 시작 시점에 집계됨 ([fliki](https://fliki.ai/blog/youtube-shorts-algorithm-explained)). 조회수보다 **유지율·루프율·프로필 클릭**을 봐야 함.
- 법률 정보 쇼츠는 무음 시청이 많음. 화면 자막이 핵심이고, 내레이션은 보조.
- 쇼츠 설명란·댓글 링크는 클릭되지 않음. CTA는 "프로필 링크"와 채널 설명 링크, 관련 동영상 연결로 유도.

(출처 내용은 라이선스 준수를 위해 요약·재구성함)

### 1-4. 경쟁·시장 관찰

- 기존 개인회생 쇼츠는 대부분 개별 법률사무소 광고: "무료상담", "전문 변호사", "탕감", "후기" 위주. 이 표현들은 내부 규칙상 사용할 수 없음.
- 차별화 방향: 결과를 약속하지 않고 **과정의 불안(전화·노출·서류·선택)**을 줄이는 도구로 포지셔닝. "상담 전에 정리하고, 번호 대신 가명으로, 내가 고른다."

## 2. 컴플라이언스 가이드 (모든 편 공통, 게시 전 필수)

`scanCompliance()` 규칙 기준. 대본 확정 후 스크립트 전체를 검사기에 넣어 high 0건을 확인하고 게시.

| 금지 (high, 게시 차단) | 대체 표현 |
|---|---|
| 100%·무조건·반드시 + 탕감/면책/인가/해결 | "요건을 충족하면 법원 기준에 따라 검토됩니다" |
| 탕감·면책 보장/확정/약속 | "인가·면책은 법원이 판단합니다" |
| 국내 최초·업계 1위·최고의 변호사 | 사용하지 않음 |
| 성공률·인가율·면책률 | 사용하지 않음 |
| 역경매·입찰·최저가·수임료 할인 | "변호사 정보를 확인하고 직접 선택" |
| 출처 없는 % / 배 수치 | 사용하지 않음 |
| 변호사법 100% 준수·검수 완료 | 사용하지 않음 |

| 수정 권고 (medium) | 대체 표현 |
|---|---|
| 무료 상담 | "상담 신청", "익명 체크는 이용료 없이" |
| 개인회생 전문 변호사 | "개인회생 사건 경험 변호사" |
| 유출 0%·전화 0통·완벽 차단 | "010 번호를 공개하지 않고" |
| 빚 0원·인생역전·기적 | 평이한 정보 문장 |
| 실제 후기·○○씨 사례 | 가상 상황은 화면에 "예시 상황" 표기 |
| 변호사 연결해 드립니다·맞춤 매칭 | "직접 선택" |

추가 규칙
- 엔드카드와 설명란에 짧은 고지문을 반드시 삽입:
  > 마이김변은 리걸테크 플랫폼이며, 상담·수임은 의뢰인이 선택한 법률사무소가 수행합니다. 인가·면책은 법원이 판단합니다.
- "100% 익명"은 허용된 표준 용어. 그 밖의 절대 표현은 쓰지 않음.
- 실존 인물·실제 의뢰인 얼굴 사용 금지. 사실적인 AI 생성 인물·장면을 쓰면 업로드 시 YouTube "변경되거나 합성된 콘텐츠" 항목을 체크.
- 화면 녹화는 데모 계정·더미 데이터만 사용 (실제 의뢰인 정보·사건번호 노출 금지).
- 법 조항·실무 기준을 언급할 때는 "법원·사건마다 다를 수 있음"을 자막으로 같이 표기.

4. 숨은 채무 조회(`api/debt-discovery.js`)는 코드에 목업 생성기가 있어 실서비스 여부 확인 전까지 영상 소재에서 제외함.
5. 카카오 채널 URL이 코드에 없음. 채널 개설 시 엔드카드 CTA에 추가 가능.
6. 기존 사이트 문구 중 "도산 전문 변호사", "실제 이용자들의 후기"(`index.html`, `public/about.html`)는 영상 문구 규칙과 충돌하므로 영상에서 재사용하지 않음. 사이트 문구 정리도 권장.
7. #5(채무자대리인), #6(금지·중지명령), #7(투자 손실 기준) 대본은 게시 전 제휴 변호사의 법률 검토 권장. 검사기는 1차 필터일 뿐 법률 검토를 대신하지 않음.
