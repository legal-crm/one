## 1. 핵심 정리: Antigravity vs Claude Code

| | Antigravity (현재 사용 중) | Claude Code |

| **개발사** | Google DeepMind | Anthropic |

| **모델 교체** | ❌ Claude로 변경 불가 | ✅ Claude Opus 5.5 기본 지원 |

> **결론:** Antigravity CLI(`agy`)는 Gemini 전용이므로 Claude Opus 5.5로 **모델을 교체할 수 없습니다**. 대신 아래 3가지 방법이 있습니다.

## 2. Claude Opus 5.5 연동 방법 3가지

### 방법 A. Claude Code 직접 설치 (⭐ 추천)

Anthropic의 공식 에이전틱 코딩 CLI인 **Claude Code**를 설치하여 Claude Opus 5.5를 직접 사용합니다.

#### 설치 방법 (Windows)
```powershell
# 방법 1: PowerShell 네이티브 설치 (추천)
irm https://claude.ai/install.ps1 | iex

# 방법 2: WinGet
winget install Anthropic.ClaudeCode

# 설치 확인
claude --version
claude doctor
```

#### API 키 설정
```powershell
# Anthropic 콘솔에서 API 키 발급 후 환경변수 설정
# https://platform.claude.com/ → Settings → API Keys
$env:ANTHROPIC_API_KEY = "sk-ant-..."

# 또는 Windows 환경변수에 영구 등록
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-...", "User")
```

#### 프로젝트에서 Opus 5.5 사용
```powershell
# 마이김변 프로젝트 루트에서 실행
cd "c:\Users\JSH\Downloads\legal-crm---회생파산-상담-플랫폼"

# Claude Opus 5.5 모델로 시작
claude --model claude-opus-5.5

# 또는 세션 내에서 모델 전환
# /model claude-opus-5.5
```

#### 인증 방법 (택 1)

| **구독 로그인** | `claude` 실행 후 Anthropic 계정 로그인 | 월 \$20~\$200 (구독 플랜) |
| **API 키** | `ANTHROPIC_API_KEY` 환경변수 설정 | 사용량 기반 종량제 |

### 방법 B. 하이브리드 운영 (Antigravity + Claude Code 병행)

현재 Antigravity(Gemini)를 유지하면서 Claude Code를 **병행** 사용하는 전략입니다.

```
┌─────────────────────┐    ┌─────────────────────┐
│  Antigravity (Gemini)│    │  Claude Code (Opus)  │
│  ─ 빠른 리서치        │    │  ─ 심층 코드 리뷰     │
│  ─ 파일 탐색/편집     │    │  ─ 복잡한 리팩토링    │
│  ─ 서브에이전트       │    │  ─ 보안 감사          │
│  ─ 단순 수정         │    │  ─ 아키텍처 개선      │
└─────────────────────┘    └─────────────────────┘
```

**작업 분류 기준:**
| 작업 유형 | 추천 도구 | 이유 |
|:---|:---|:---|
| 파일 탐색, 단순 수정, 배포 | Antigravity (Gemini Flash) | 빠르고 저렴 |
| 보안 감사, 비즈니스 로직 검증 | Claude Code (Opus 5.5) | 깊은 추론력 |
| 대규모 리팩토링 | Claude Code (Opus 5.5) | 복잡한 코드 변경 |
| 일상적 코드 수정 | Claude Code (Sonnet 5) | 중간 비용 |

### 방법 C. Anthropic API 직접 호출 (스크립트 기반)

체크리스트 항목을 일괄로 검증하는 자동화 스크립트를 작성합니다.

```typescript
// 예시: 체크리스트 항목별 자동 코드 검증 스크립트
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

const response = await client.messages.create({
  model: "claude-opus-5.5-20260922",
  max_tokens: 8192,
  messages: [{
    role: "user",
    content: `다음 코드를 분석하고 체크리스트 항목이 정상 구현되었는지 검증하세요:
    체크리스트: "AES-256-GCM 필드 레벨 암호화 정상 작동"
    코드: ${sourceCode}`
  }]
});
```

Threads 게시자 `@_ddhyunkk`가 공개한 오픈소스 도구로, 여러 Kiro 계정의 잔여 크레딧을 자동으로 확인하고 남은 계정으로 전환해줍니다.

```bash
# 설치
git clone https://github.com/beyondfashion-ai/kiro-account-router

# 계정별 잔여 크레딧 확인

# 자동으로 크레딧 남은 계정 선택 후 시작 (엔터=자동)
```

> **팁:** WSL에 계정 하나, Windows(PowerShell)에 계정 하나 로그인해두면 둘 다 자동으로 잡아서 사용합니다. 키쫀쿠(월말 추가 계정)와 조합하면 크레딧을 더 효율적으로 쓸 수 있습니다.
