## 0. 한눈에 보기

**결론**

1. 뼈대는 방향이 맞습니다. 네이비 브랜드, Pretendard, 4단계 이용 가이드, 가명 상담 콘셉트, 광고 표시·면책 고지 같은 기반은 유지할 가치가 있습니다.
2. 다만 디자인을 다듬기 전에 고쳐야 할 것이 먼저 있습니다.
   - **깨져 보이는 핵심 화면**: 데스크톱 '내 상황 체크하기'(챗봇), 모바일 푸터·선택 확정 바 가림, OS 다크모드에서 제목이 사라지는 문제
   - **사실과 다른 표시**: 가짜 기본값, 시연 데이터, 항상 켜진 상태 배지, 저장되지 않았는데 '저장 완료'
   - **법무 검토가 필요한 문구**: '나의 채무관리 변호사', '법률 상담사 김변', '전문 변호사', '100% 법적 효력' 등
3. 화면마다 디자인 언어가 다릅니다. 하드코딩 색상 390곳(브랜드와 다른 보라 #7264FF 89곳), 12px 미만 글자 701곳, 모달 셸 제각각, 페이지 헤더 6종이 있습니다.
4. 제안은 5단계(Phase 0~4)입니다. **Phase 0(신뢰·안정화) → Phase 1(디자인 시스템 기반)** 을 먼저 하고, 그 부품으로 화면을 재구성(Phase 2~3)하는 순서를 권장합니다.
5. 예상 규모는 전체 약 40~55 작업일(1인 기준 추정), 최소안(Phase 0)은 약 6~8일입니다.

## 1. 점검 범위와 방법

- **범위**
  - 셸: `ClientRole.tsx`(헤더·안내 띠·모바일 GNB·푸터·전역 모달)
  - 탭 14개
  - 독립 화면 4개: 원격 전자서명, 공유 리포트, 서류 공유 열람, 계약 진위 확인
  - 서류 작성 모달군, 회생동행
- **방법**
  1. 코드 리뷰: 7개 영역으로 나눠 파일·라인 단위로 확인
  2. 화면 캡처: 로컬 개발 서버에서 데스크톱 1440px / 모바일 390px, 비로그인 상태로 촬영하고 OS 다크모드도 추가 캡처. 쓰기 요청은 모두 차단하고 읽기만 수행
  3. 자동 측정: 텍스트 대비, 12px 미만 글자, 터치 영역, 가로 넘침
  4. 규칙 대조: 프로젝트 디자인 규칙(`.agents/AGENTS.md` R1~R5) 기준 정량 집계
- **한계**
  - 로그인 후 화면(내 관리방·마이페이지·회생동행 대시보드)은 실제 데이터로 렌더링하지 못해 코드 기준으로 판단했습니다.
  - 대비 수치는 자동 측정 근사치입니다. WCAG 준수 여부는 보조기기 수동 테스트와 전문가 검토가 별도로 필요합니다.
  - 법률 문구는 '검토 필요'까지만 판단했습니다. 최종 판단은 법무 검토 대상입니다.

## 4. 공통 디자인 시스템 진단

**토큰**

- `index.css`의 폰트 크기 재정의(`--font-size-*`)가 Tailwind v4에서 무시됩니다. text-xs가 의도한 13px가 아니라 12px로 동작하므로 `--text-*`로 이름을 바꿔야 합니다.
- dark 변형이 OS 설정을 따릅니다. 정책을 정해야 하며, 당장은 라이트 고정을 권장합니다.
- 브랜드 토큰이 있는데도 hex를 직접 쓴 곳이 많습니다(#1E3A5F 145곳).
- 토큰에 없는 반복 색이 있습니다: #0F172A, #1A3C4D, #2B3E50, #111827.
- 보라 계열이 섞여 있습니다: #7264FF, #5B4CF5.
- 정의되지 않은 색 단계가 214곳이라 테두리·배경이 의도와 다르게 나옵니다.
- z-index 스케일이 없습니다: 50, 60, 100, 999, 9999, 10000, 99999가 혼재합니다.

**컴포넌트**

- 모달 셸이 제각각입니다. 포털은 일부만 쓰고, role="dialog"는 5곳, ESC·포커스 트랩은 대부분 없으며, 모바일 풀스크린은 1종뿐입니다.
- 같은 역할의 부품이 여러 버전입니다: 페이지 헤더 6종, 페이지네이션 3종, 빈 상태 7종, 검색창 4종.
- 주 CTA 색이 6종입니다: brand, indigo, blue, emerald, 그라디언트 2종.

**가독성·톤**

- 12px 미만 글자가 701곳입니다. 고령·저시력 사용자가 많은 서비스라 체감이 가장 큰 항목입니다.
- font-black 307곳, 그라디언트 160곳, 이모지 약 568개로 법률 서비스 톤에 비해 장식이 많습니다.

**상태·모션·접근성**

- 스피너 18곳. 탭 공통 로딩이 스피너이고, 일부 탭(회사소개·이용안내)은 로딩 중 빈 화면입니다.
- `prefers-reduced-motion` 대응이 0건입니다. 무한 pulse·bounce·ping 34곳과 후기 마키가 있습니다.
- 클릭 가능한 div(키보드로 조작 불가)가 있고, 아이콘 버튼 라벨이 빠진 곳이 있습니다.

**유지할 강점**

- `ServiceGuideSection`의 WAI-ARIA 탭(키보드 조작), `TrustFactsBar`의 검증 가능한 사실만 표시하는 방식
- 후기 '예시(가상)' 표기, 광고 표시와 검색 투명성 바, 변호사 프로필 모달의 광고규정 고지와 ESC 닫기
- 네이티브 alert가 1곳만 남은 점, 챗봇의 답변 수정(롤백)·이탈 확인·세션 자동 저장
- 로그인 모달의 모바일 바텀시트, `rounded-[Npx]` 하드코딩 0건
