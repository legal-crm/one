# [기획서] "투더코어(ToTheCore)" 벤치마킹 기반 개인회생·파산 자동작성 및 전자소송 연동 고도화 기획안

> **문서 버전**: v1.0  
> **기준 일자**: 2026-09-15  
> **시스템**: 마이김변(legal-crm) 변호사 어드민 & 도산 서류 작성 시스템  
> **핵심 원칙**: **기존 기능 100% 유지(하위 호환성 완전 보장)** + **투더코어 실무 노하우 Additive(확장형) 통합**

## 1. 기존 기능 보존 원칙 (하위 호환성 100% 보장)

> [!IMPORTANT]
> **기존 기능에서 빠지거나 삭제되는 기능은 전혀 없습니다 (100% 유지).**

본 고도화 작업은 기존의 안정적인 CRM 인프라와 서류 작성 기능을 전혀 손상시키지 않고, 그 위에 투더코어의 고도화된 실무 디테일을 얹는 **확장형(Additive) 고도화**입니다.

### 🛡️ 보존되는 기존 핵심 기능 목록
1. **변호사 어드민 CRM & 통합 5단계 파이프라인 (Stage 1~5)**:
   - 상담 접수, AI 사건 진단, 수임 계약, 전자계약서 발송, 카카오 알림톡, 결재선(변호사-직원) 일체 유지.
2. **부채증명서 발급 대행 주문 & 의뢰인 모바일 서류 수합**:
   - 발급처 4대 카테고리(주민/국세/직장/금융) 및 제3자 주민번호 뒷자리 마스킹 검증 유지.
3. **법원 전자소송 7대 묶음 순서정렬 PDF 결합 & ZIP 다운로드**:
   - `CourtBatchFilingService`의 7대 묶음 ZIP 압축 및 기존 대법원 규격 유지.
4. **로패스(LawPass) 스타일 10대 아코디언 양방향 사이드바 (`LawPassCourtFilingSidebar`)**:
   - 실시간 Live Binding 및 5대 특약 문구 삽입기 완전 유지.
5. **기존 변제계획안 계산 엔진 (`repaymentCalculationEngine.ts`)**:
   - 2026 기준중위소득 60% 생계비, 기본 36개월 가용소득 분배 알고리즘 기본값 보존.
6. **개인파산 전용 관리 탭 (`BankruptcyManagementTab`)**:
   - 파산 신청서 및 관재인 보고서 모달 유지.

### 모듈 1. 대법원 전자소송 CSV 무결성 & 안전 업로드 패키지

- **배경 및 문제점**:
  - 대한민국 법원 전자소송 시스템은 채권자 전화번호에 전국대표번호(`1588-xxxx`, `1544-xxxx`, `1566-xxxx`, `1600-xxxx` 등)가 입력되면 정규식 검증 에러로 업로드가 중단됩니다.
  - 사용자가 다운로드한 CSV를 엑셀에서 확인 후 저장하면 UTF-8 BOM 인코딩 및 따옴표가 깨져 오류가 발생합니다.
- **구현 내용**:
  1. `CourtBatchFilingService.generateCourtCreditorCsv`:
     - 채권자 전화번호 필드에 `1588`, `1544`, `1566`, `1600`, `1644`, `1688` 등이 감지될 경우 자동으로 앞에 `02-`를 붙여 `02-1588-xxxx`로 변환.
     - 전화번호가 없거나 공란일 경우 기본 지역 국번 매핑.
  2. 다운로드 UX 개선:
     - CSV 다운로드 모달에 **"⚠️ 전자소송 업로드 주의: 다운로드된 CSV를 엑셀에서 열어 '저장'하시면 서식이 깨져 전자소송 업로드 오류가 발생합니다. 다운로드된 원본 파일을 그대로 첨부해 주세요."** 시각적 경고 카드 배치.
     - 클립보드 복사(전자소송 웹 직접 붙여넣기용) 버튼 병행 제공.

### 모듈 2. 채권자목록 7대 옵션 기반 부속서류 1~4 완전 자동화

- **배경 및 문제점**:
  - 채권자목록 작성 시 부속서류 1(별제권부), 부속서류 2(다툼), 부속서류 3(전부명령), 부속서류 4(보증채무/구상권)를 따로 작성하려면 매우 번거롭고 숫자가 불일치하는 실수가 잦음.
- **구현 내용**:
  1. `RepaymentCreditor` 인터페이스에 투더코어 7대 옵션 플래그 정밀화:
     ```typescript
     export interface RepaymentCreditor {
       // ... 기존 필드 ...
       // 투더코어 7대 실무 옵션
       isPriority?: boolean;         // 1. 우선변제 (세금, 4대보험)
       isSecured?: boolean;          // 2. 담보/별제권 (부동산, 차량, 전세보증금)
       isGuarantorClaim?: boolean;   // 3. 구상권 (신보, 기보, 서울보증 등 장래구상채권)
       isGuaranteedDebt?: boolean;   // 4. 보증채무 (신청인이 타인 위해 보증)
       isDisputed?: boolean;         // 5. 다툼 (원금/이자 다툼)
       isGarnished?: boolean;        // 6. 전부명령 (급여 전부명령)
       isTrustUnconfirmed?: boolean; // 7. 미확정채권 (담보신탁 등)
       
       // 부속서류 산출용 상세 메타
       securedCollateralType?: 'REAL_ESTATE' | 'VEHICLE' | 'LEASE_DEPOSIT' | 'OTHER';
       collateralAppraisalValue?: number; // 담보물 평가액
       securedMaxAmount?: number;         // 채권최고액 (또는 보증금)
       priorSecuredAmount?: number;       // 선순위 담보액
       unsecuredExpectedShortage?: number;// 별제권 행사 등으로 변제받을 수 없는 금액 (부속서류 1 예정부족액)
       
       disputeCreditorClaim?: number;     // 채권자 주장액 (부속서류 2)
       disputeDebtorClaim?: number;       // 신청인 주장액 (부속서류 2)
       disputeReason?: string;            // 다툼 원인
       
       garnishmentAmount?: number;        // 전부금액 (부속서류 3)
       garnishmentCourtCase?: string;     // 전부명령 법원 및 사건번호
       
       principalDebtorName?: string;      // 주채무자 (부속서류 4)
       guarantorName?: string;            // 보증인 / 구상권자 (부속서류 4)
       subrogationStatus?: 'BEFORE' | 'AFTER'; // 대위변제 전/후
     }
     ```
  2. 자동 계산 로직:
     - **부동산 담보**: 환가예상액의 70%를 기준으로 별제권 유담보액과 예정부족액 자동 분할.
     - **차량 담보**: 연식 기준 50%~70% 환가액 기준으로 예정부족액 자동 계산.
     - **임차보증금 반환 채무**: 임차인의 대항력/우선변제권 및 최우선 소액보증금액 자동 판정하여 별제권 처리.
  3. 목록 정렬 듀얼 모드:
     - **[자동 정렬]**: ① 담보부(별제권) ➔ ② 우선변제(세금) ➔ ③ 일반 신용채권(발생일자 오름차순)으로 채권번호 1, 2, 3... 자동 정렬.
     - **[수동 정렬]**: 실무자가 드래그 앤 드롭으로 임의 순서 변경 가능.

### 모듈 3. 법원 보정권고 전용 튜닝 컨트롤러 (`RepaymentTuningBox`)

- **구현 내용**:
  1. **추가변제월 컨트롤 (음수 단축 지원)**:
     - 법원의 "변제기간을 늘려라" 보정권고 시: +1개월 ~ +24개월 슬라이더로 총 37~60개월 변제안 생성.
     - 서울회생법원의 "이자 변제기간을 단축하라" 보정권고 시: -1 ~ -12개월 입력 지원 (원금 100% 변제 회차에 맞춰 변제기간 자동 단축).
  2. **가용소득 수동 오버라이드**:
     - 법원의 가용소득 증액 권고(예: 월 80만원 ➔ 월 95만원)를 수용할 때, 생계비 공식과 무관하게 지정된 가용소득으로 채권자별 안분표를 즉시 재계산.
  3. **압류적립금(중지명령) 인가 후 투입**:
     - 급여 압류 후 중지명령으로 회사에 유보된 압류적립금 입력 시, 인가 직후 1회차 변제금에 합산 투입하여 초기 변제율을 획기적으로 높이는 변제계획안 자동 산출.
  4. **최저변제율 안전망 & 개시후이자 안내**:
     - 총채무 5천만원 미만(최저 5%), 5천만원 이상(최저 3% + 100만원) 충족 여부 실시간 표시.
     - 청산가치 보장을 위해 60개월로도 부족하여 총변제액이 원리금을 초과하는 특이 사건의 경우:
       *"청산가치 보장을 위해 개시후이자를 입력하거나 재산 목록의 평가액을 재검토하세요"* 알림 배너 표시.

### 모듈 4. 서울회생법원 2021 실무준칙 '원금형' 특례 엔진

- **구현 내용**:
  1. `RepaymentFormType`에 `'SEOUL_PRINCIPAL_ONLY'`(서울회생법원 원금형) 옵션 신설.
  2. 변제계획안 작성 시 서울회생법원 사건이거나 해당 옵션을 켜면:
     - 36개월 이내에 가용소득으로 원금이 100% 변제되는 시점(예: 28회차)을 감지.
     - 29~36회차의 이자 변제기간을 일괄 삭제하고 **"총 28개월간 원금 100% 변제 완료"** 변제계획안 및 변제예정액표 자동 생성.
     - 타 관할 법원(원리금형)을 위한 기존 36개월 균등 변제 방식은 기본값으로 유지.

### 모듈 5. 재산 및 수입지출 실무 규칙 정밀화

- **구현 내용**:
  1. **배우자 소유 자산 처리 룰**:
     - 신청인 소유: 민사집행법 제246조(예금 185만, 보험 150만, 주임법 소액보증금) 자동 공제.
     - **배우자 소유 체크 시**: 압류금지 공제를 **0원(미공제)** 처리하고 자산가액의 1/2을 청산가치에 반영.
     - 실무 소명용 **배우자 기여분 조정 슬라이더(기본 50%, 필요 시 10%~40%로 수동 조정)** 지원.
  2. **부양가족 소수점(1.5인, 2.5인) 지원**:
     - 부모님 형제 분담 부양, 이혼 자녀 양육비 분담 시 `1.5인`, `2.5인` 입력 지원.
     - 해당 구간의 기준중위소득 60% 생계비를 선형 보간(Interpolation)으로 정확하게 자동 산출.
  3. **기준중위소득 연도 선택**:
     - 2025년 기준 vs 2026년 기준 선택 셀렉터 지원 (해를 넘긴 보정 사건 완벽 대응).
  4. **양육비 재단채권 옵션**:
     - 외부회생위원 보정권고에 따라 양육비를 가용소득에서 공제하여 재단채권으로 변제하는 특약 문구 자동 추가.

### 모듈 6. 회생-파산 단일 데이터 파이프라인

- **구현 내용**:
  1. 개인회생에서 입력된 채권자 목록 및 부채증명서 데이터를 그대로 개인파산 탭(`BankruptcyManagementTab`)과 100% 공유.
  2. 파산 모드 전환 시 파산 전자소송 필수 항목 활성화:
     - **최초원금**: 최초 차용 원금
     - **발생원인**: 대출, 카드대금, 물품대금 등
     - **사용처**: 생활비, 사업자금, 병원비, 피보증인명(보증채무 시), 원채권자 사용처 승계(대위변제 후 구상채권 시)
  3. 개인파산 전자소송 규격 채권자목록 CSV 원클릭 내보내기 지원.
