## 7. 과금 · 광고 신청/입금 관리 — `AdminRole` adorders 서브탭
- **현황:** 입금은 관리자가 통장을 보고 수동 확인 → 세금계산서 발행. **광고 주문을 활성화해도 실제 노출로 이어지지 않음**(3-4).
- 🔴 활성 광고 → 고객 사이트 노출 연결: 홈 Hero 슬라이더(메인 배너), **홈 중간 변호사 소개 배너**, 변호사 찾기 상단·지역 (SA-Q2, 고객 기획서 1-B·1-C)
- 🔴 노출 시작 조건 = 입금 확인 + 소재 승인, 만료일 자동 종료
- 🔴 홈 변호사 소개 배너 = 메인 배너·상단 노출 광고 변호사 + 빈자리는 실사진 있는 승인 등록 변호사('등록 변호사' 표시). 관리자 화면에서 현재 노출 구성 미리보기 (고객 기획서 1-C)
- 🔴 광고 소재 업로드·심사·승인 흐름 (광고 표시, 광고 책임 변호사, 과장·결과 보장 금지) (마스터 4-1)
- 🔴 만료 처리: 만료일 지나면 자동 '만료', 7일 전 갱신 안내
- ⚪ 카드 결제·가상계좌 자동 입금 확인 (feature_expansion_plan 12번)
