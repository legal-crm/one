## 0. 결론 먼저

1. **우리 파산 작업 화면은 만들어져 있는데 열 수가 없어요.** `BankruptcyManagementTab`(신청서·진술서 감수·면책불허가 점검·채권자·관재인 5대 조사재산·생활상황·15개 자료제출목록)과 인쇄 모달(`PrintableBankruptcyPetitionModal`)은 `CrmTab`에 불러오기만 하고 화면에 붙어 있지 않아요. 파산 사건도 회생 6단계 화면을 그대로 써요.
2. **파산 서식 출력이 사실상 없어요.** 서식 작성기는 회생 13종뿐이고, 파산 HWPX는 빈 양식, 4단계 '파산 7대 서식' 카드는 회생 데이터(재산목록 D5102·회생 수입지출)를 보고 준비 여부를 표시해요. 표시 코드 'D7101·D7103'도 근거 없음.
3. **파산 판정이 엉뚱한 곳이 있어요.** 전자소송 묶음·서식 허브·1단계 일부가 사건 유형 대신 "소득 0원이거나 채무 5억 초과"로 파산 여부를 추정해요 → 소득 있는 파산 사건에 회생 순서·회생 CSV가 나갈 수 있어요.
4. **파산 절차 단계가 회생 문구예요.** 6단계 레일 이름만 '심문·선고 / 파산·면책'으로 바뀌고, 체크리스트는 '회생위원 가상계좌·채권자집회 인가'예요. 파산선고·동시폐지/관재·관재인·이의신청기간·면책심문·면책확정 기록칸이 없어요(13단계 진행표에는 파산 단계가 있음).
5. **파산 CSV도 형식이 달라요.** 우리 17열 자체 형식 + 빈 값 지어내기(`2023-01-01`, `대출금`, `생계비 및 생활비`, `보증기관`). 로패스·디던비 파산 CSV는 **둘 다 같은 18열**(`체크(기본값 F)`, 채권자목록번호, 보증인번호 … 발생원인 번호 ①~④, 최초채권액, 사용처, 잔존원금, 잔존이자및지연손해금)이에요(10-29 재확인, 05 기획서 8장).
6. **경쟁사 수준:** 로패스는 공식 파산 진술서 문항 전부 + 표지·신청서·송달장소 신고서·위임장까지 14쪽 한 번에, 디던비는 지급불능일 기준 입력·서류 자동 반영·항목별 작성 안내가 강점(단 파산 신청서 자체는 출력 목록에 없음).

### 1-1. 문서 순서 (전체 출력)
- 로패스: 표지 → 파산및면책신청서 → 송달장소 신고서 → 위임장 → 진술서 → 채권자목록 → 재산목록 → 현재의 생활상황 → 수입및지출
- 리걸프렌즈 입력 순서: 기본사항 → 진술서 → 채권자 목록 → 재산목록 → 생활상황 → 수입 및 지출 → 소송위임장 → 출력
- 우리 묶음 규격(`BANKRUPTCY_10_STANDARD_ORDER`): 신청서 → 진술서 → 진술서 소명자료 → 채권자목록 → 부채증명서 → 재산목록 → 생활상황 → 수입지출 → 자료제출목록 → 위임장
- → 회생과 마찬가지로 **실제 파산 접수본**(BK-Q3)으로 순서를 확정하고, 출력 경로 하나로(05 기획서 H-8).

## 3. 파산 절차 진행 관리 (우리에게 가장 부족한 부분)

회생은 '개시결정 → 채권자집회 → 인가 → 변제 → 면책'이지만 파산은 흐름이 달라요. 지금 6단계 레일은 회생 기준이라 5·6단계를 파산용으로 나눠야 해요.

| 단계 | 회생 (지금) | **파산 (바꿀 것)** | 기록·알림할 값 |
|:---:|:---|:---|:---|
| 1~3 | 상담·제안 / 수임 계약 / 서류 준비 | 같음 (서류 목록은 파산용 15종, 이미 있음) | - |
| 4 | 신청·접수 | 신청·접수 (파산 서식·CSV·비용) | 접수일, 파산 사건번호(하단)·면책 사건번호(하면) |
| 5 | 보정·개시 | **보정·파산선고** | 보정 내역, 파산선고일, **동시폐지 / 관재 사건 구분**, 관재인 이름·연락처·사무실, 관재인 보수 예납 안내·납부일, 관재인 면담일·요청 자료 목록·제출일, 채권자집회(재산상황 보고) 기일, 환가·배당 메모, 파산폐지(이시폐지)일 |
| 6 | 변제·면책 | **면책** | 이의신청기간 만료일, 면책심문기일, 면책결정일·확정일, 면책불허가 시 대응, 비면책채권 안내(조세·벌금·양육비 등), 사후관리(신용정보 해제 확인) |

- 일정 값은 캘린더·알림톡·의뢰인 화면(회생동행 파산 모드, 13단계 메시지 이미 있음)에 연결해요.
- 의뢰인 화면에는 진행 단계·일정만 보여 주고, 동시폐지·면책 가능성 같은 판단은 보여 주지 않아요(제109조 원칙).

## 5. 보강 계획 (개발 BK 트랙)

### 🔴 출시 전 — 파산 사건을 받을 수 있는 최소선

- **BK-1 파산 작업 화면 연결:** 파산 사건이면 4단계 '신청 서식'에 파산 작성 화면을 열어요(형태는 BK-Q2). 파산 여부는 **사건 유형 값 하나로만** 판단(추정 3곳 제거). 회생→파산 전환 때 채권자(부채증명서 반영분)·재산·소득을 이어받고, 파산에 필요한 칸(최초 채권액·사용처·발생원인 번호·보증인)만 비워 확인 표시.
- **BK-2 파산 서식 데이터 채움 출력:** 표지, 파산및면책신청서(정보수신 신청·지원기관 기재란), 송달장소 신고서, 위임장, 진술서(공식 문항 전부), 채권자목록(채권내역 + 주소표), 재산목록(14항목 요약표 + 상세), 현재의 생활상황, 수입및지출(직전 달 기준월 자동 + 가용소득표), 자료제출목록(법원별). 출력은 회생과 같은 글자 PDF 엔진·검증 게이트(05 기획서 H-7·H-8·H-3)를 써요. 사건번호 연도·기준월은 신청일에서 계산(고정값 금지).
- **BK-3 파산 CSV (10-29 형식 확정):** 18열 채권자목록형 — 디던비(CP949)·로패스(UTF-8 BOM) 두 회사 머리글이 완전히 같아요. 투더코어 안내대로 파산은 전자소송에 CSV만 올리면 채권자목록이 만들어지므로 최초채권액·발생원인 번호·사용처·잔존원금·잔존이자가 필수예요. 보증인은 같은 채권자목록번호 + 보증인번호 `1`. 지어낸 기본값 삭제, 비면 출력 전 경고. (앞서 '디던비 13열이 회생·파산 공통'이라고 적은 것은 잘못이에요. 디던비 파산 출력도 18열이었어요.) 채권자목록번호(`채권1`/`1`)·날짜(`2026.01.01.`/`2024.03.01`)·인코딩은 포털 양식 파일로 최종 확인(CF-Q2).
- **BK-4 파산 데이터 모델 정리:** 지급불능 시점(날짜) 추가 — 처분재산·차용·편파변제 질문 기간 계산에 사용, 진술서를 공식 문항 구조로(지금 8개 점검은 '변호사 검토 메모'로 유지), 채권자 발생원인 번호·최초 채권액·사용처·보증인 번호, 동거가족 월수입 → 부양가족 판정(기준 금액은 연도별 기준표 단일 출처, B-3), 주민번호 저장 제거(L8), '1,110만 원' 고정 제거.
- **BK-5 파산 단계 분기:** 5단계 '보정·파산선고', 6단계 '면책'으로 체크리스트·섹션·안내문 교체(3장 표). 기록칸: 파산·면책 사건번호, 선고일, 동시폐지/관재, 관재인 정보·면담·요청 자료·제출일, 예납 납부일, 채권자집회 기일, 이의신청기간 만료일, 면책심문기일, 면책결정·확정일. 모두 서버 저장 + 캘린더·알림톡·의뢰인 화면 연결.
- **BK-6 파산 비용:** 인지(파산·면책), 송달료 1회 5,640원·파산 10+4n·면책 10+3n, 관재인 보수 예납금 관할별 설정표(서울 40만·유관기관 30만, 다른 법원은 사무소 확인 후 입력) → 계약 위저드 실비 항목·수임료 화면과 연결. (10-29 공식 자료 반영, 상세 7장)

- **BK-10 실제 서류 대조 (10-29 신설):** 출시 전에는 공식 양식 원문(7-4)을 정답 데이터로 쓰고, 실제 파산 접수본을 구하면 대조·보정.

### 🟡 출시 직후

- **BK-7 의뢰인 참여:** 파산 진술서 작성 요청 → 의뢰인 화면 작성 → 변호사 검토 반영(회생과 같은 흐름), 관재인 요청 자료 제출 요청.
- **BK-8 의뢰인 화면:** 회생동행 파산 사건 서버 저장, 파산 단계·일정 안내(관재인 면담·채권자집회·면책심문), 회복 아카데미에 파산·면책 후 생활 내용 추가. 진단·가능성 표시는 하지 않음.
- **BK-9 파산 자료 자동입력:** 회생과 같은 엔진(05 기획서 CF-Q3 결정 따름)으로 부채증명서·계좌·보험·급여 → 파산 채권자·재산·수입 반영.

### ⚪ 출시 후

- 관재인 대응 기록(요청 자료 체크리스트·제출 이력·보고), 환가·배당 메모, 채권자 이의 대응, 면책 후 비면책채권 관리, 파산 부속 신청서(중지·금지명령, 면제재산 결정신청 등, H-1 3묶음).

### 7-4. 공식 양식 (서울회생법원 민원서식·실무준칙 제407호 원문)
- **신청 필수:** 파산및면책신청서(동시신청서, 정보수신 신청·법원 외 기관 지원 기재란 포함) · 진술서 · 채권자목록(채권내역 + 채권자 주소) · 재산목록 · 현재의 생활상황 · 수입및지출에 관한 목록 · 자료제출목록. 대리인 신청이면 위임장, 송달장소 신고서.
- **진행 중 자주 쓰는 것:** 면제재산 결정신청서, 채권자목록 변경 신고서, 송달되지 않는 채권자에 대한 공고갈음 신청서, 예납금납입 보정서·예납비용 납부기한 연장/감액 신청서, 중지명령 신청서, 재산조회신청서, 소송구조신청서(송달료·지정변호사), 휴대전화 알림서비스 신청서, 불출석사유서, 즉시항고장, 복권신청서. 상속재산 파산신청서(상속인/상속인 외).
- **채권자목록 기재요령(원문 요약):** 채무별로 순번, 같은 채권자의 여러 채무는 오래된 것부터 연이어 / 법인은 대표자까지, 별칭 금지 / 보증인이 있으면 보증인란 기재, **보증으로 인한 구상채무는 보증한 채무 바로 다음에 가지번호(예: 3-1), 잔존액은 '미정'** / 채권양도는 양도일자를 ( )로 추가 / 발생원인은 ①금원차용 ②물품구입 ③보증(피보증인 기재) ④기타 / 최초 채권액·사용처(구체적 용도·구입물품) / 잔존 원금·이자·지연손해금과 합계 필수 / 채권자 주소는 신청일 당시 번지까지, 법인은 본점 또는 거래지점.
- **추가 진술사항 문항:** 사기·사기파산·과태파산·도박죄 고소·재판 / 1년 내 할부 물건 처분 / 개인 영업 경험(상업장부 기장, 염가 매각, 사실증명 8종) / 채권자와 교섭·합의·지급 내역 / 지급불능 계기·**시점** / 지급불능 후 차용 / 지급불능 후 일부 채권자에게만 변제 / **지급불능 1년 전부터 1,000만 원 이상 재산 처분(부동산은 금액 무관, 보험·정기예금 해약·퇴직금 수령 포함)** / 2년 내 주거이전 보증금 수령 / 2년 내 이혼 재산분여 / 친족 사망 상속.

### 7-5. 우리 계획에 반영한 변경
- **BK-2 서식 구성 확정:** 위 '신청 필수' 7종 + 위임장·송달장소 신고서 = 1차. 진행 중 서식(면제재산 결정신청, 채권자목록 변경 신고, 공고갈음, 예납 관련, 불출석사유서, 즉시항고)은 2차(H-1 3묶음).
- **BK-4 데이터 모델:** 추가 진술사항 11문항 그대로, 지급불능 시점 필수(처분재산·차용·편파변제 기간 계산), 채권자 가지번호(구상채무 '미정'), 채권양도일, 비면책 사유 9종 선택, 면책불허가 점검에 '의무 위반·구인 불출석' 추가, 자료제출목록 10분류·사유 3종.
- **BK-5 단계:** 7-1 흐름의 기한을 자동 계산해 일정으로: 선고일+7일(누락 서류 제출), 선고일+14일(면제재산 신청 기한), 선고 후 2주~1달(관재인 면담), 집회 1주 전(이의신청기간 만료 예상), 면책허가 공고+14일·불허가 송달+7일(즉시항고), 면책 확정 후 압류 해제 신청 안내. 선면책(선고+1년) 대상 표시.
