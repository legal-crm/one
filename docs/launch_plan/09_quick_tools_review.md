## 0. 한눈에 보는 결론

1. **쓸모 있는 도구가 많고 계산은 대부분 기준 엔진을 써요.** 변제율·청산가치·생계비·추가생계비는 법원 서식 엔진(`repaymentCalculationEngine`·`rehabLegalCore`)을 그대로 불러요. 사건을 열면 소득·채무·재산을 미리 채우고 '사건에 반영 / 할 일 등록 / 메모에 추가'가 돼요. 기한 계산은 민법 제157·160·161조와 공휴일(2026~2028)을 반영해요.
2. **기준값이 틀렸어요(회생·파산 공통, 06 기획서 7-3).** 압류금지 예금·급여 185만 원(→ 250만 원), 송달료 5,200원(→ 5,640원), 파산 송달 회수 8+6n(→ 10+4n, 면책 10+3n), 기준중위소득 2026 고정, 6개월 생계비 면제재산 1,110만 원(→ 2026년 15,587,371원). 도구 이름에도 '2026 기준중위소득표', '예금 185만'이 박혀 있어요.
3. **사건 연결에 버그가 있어요.** 사건을 열 때 월 변제금·기간을 읽는 필드 이름이 실제 데이터와 달라(`monthlyRepayment`/`repaymentMonths` ↔ 실제 `monthlyRepaymentTotal`/`months`) 월 변제금은 늘 0, 기간은 늘 36으로 채워져요. '사건에 반영'은 변제계획의 몇 칸만 덮어쓰고 현재가치·채권자별 배분을 다시 계산하지 않아 변제계획이 앞뒤가 안 맞게 돼요.
4. **달력과 따로 놀아요.** 일정 탭에는 월·주 달력, 다가오는 법원 기일, '기한 계산 → 할 일 + 캘린더 동시 등록'이 있는데, 퀵툴 기한 계산기는 **할 일만** 만들고 캘린더에는 넣지 않아요. 사건의 개시결정일·채권자집회일은 캘린더에 자동으로 들어가지 않고, 알림(리마인더)은 실제로 보내지 않아요(`REMINDER_DELIVERY_SUPPORTED = false`).
5. **사건과 끊긴 도구가 있어요.** 채권자 주소록 '담기'가 사건 채권자목록에 안 들어가고, 서류 체크리스트는 3단계 실제 체크리스트와 따로, 납입 안내문은 사건의 가상계좌를 읽지 않고, 스크래치 메모는 '사건 메모에 추가'가 없어요. 사건을 고르지 않은 화면(다른 탭)에서는 복사만 돼요.
6. **의뢰인에게 내보내기 위험이 있어요.** '변제율·탕감률 계산기' 결과 문구("원금 탕감 예상", 탕감률 %)를 복사해 상담창에 붙이면 RP-Q1 결정(의뢰인 화면 감면율 삭제)과 금지 용어('탕감')를 어겨요. 송달료 도구는 "상담창에 바로 붙여넣으세요"라고 안내해요.
7. **가짜 값·과장 표시:** 알림톡 바로가기가 납부 일정이 없으면 '50만 원 착수금 안내' 가짜 회차를 만들어요. 만나이 도구는 법원과 상관없이 '24개월 특례 검토 대상'으로 표시해요(`courtAllows24: true` 고정). '사건 동기화 중' 표시는 실시간 동기화가 아니에요. 배지('추천·필수·신규·편리·상담필수·서류필수…')가 많아요.
8. **화면:** 아이콘 버튼·칩·실행 버튼이 22~36px(44px 미만), 회색 아이콘 대비 부족, 휴대폰에서 퀵툴 버튼이 아래 탭 바를 가리고 창이 작은 떠 있는 상자예요. 이름이 '실무 퀵툴 / 리걸 실무 퀵툴 / 퀵독'으로 섞여 있어요. 상담 채팅 머리의 '실무 퀵툴' 버튼은 연결이 안 돼 보이지 않아요.

## 3. 새로 넣을 기능 (10-29 포함 확정)

### 3-1. 일정·기한 (요청하신 달력)

- **📅 미니 일정 (새 도구 '오늘·이번 주')**
  - 오늘·7일 안의 법원 기일·기한·상담을 한 줄씩(D-day 색 표시, 사건 이름 누르면 사건으로 이동). 일정 탭 캘린더와 같은 데이터(`calendar_events`·`task_tickets`).
  - 작은 월 달력(날짜에 점: 기일·기한·상담 색 구분 + 글자 라벨), 날짜를 누르면 그날 목록 + '일정 추가'.
  - 빠른 추가: 제목·날짜·시간·사건·유형·공개 범위(사무소/변호사/개인) — 일정 탭의 추가 창과 같은 저장 함수.
  - 전체 달력은 일정 탭에 그대로 두고, 퀵툴은 '바로 보기·바로 넣기'만 (QT-Q1).
- **⚖️ 기한 계산기 개편**
  - 근거가 붙은 프리셋: 보정명령·보정권고(명령서에 적힌 기한 입력, 흔한 값 7·14일), 즉시항고 1주(채무자회생법 제33조 → 민사소송법 제444조), 공고가 있는 결정은 공고 다음 날부터, 이의기간(법원이 정한 날짜 입력), 면제재산 신청(파산선고 후 14일), 누락 서류(선고 후 7일), 면책 즉시항고(공고 + 14일·송달 + 7일, 06 기획서 7-1). 프리셋마다 근거 한 줄.
  - '할 일 + 캘린더 동시 등록', 사건 연결 시 사건 이름·담당자 자동, 직원 등록 건은 변호사 확인(일정 탭 규칙과 같음).
  - 공휴일 자료가 없는 연도는 계산을 막고 이유 표시.
- **🔁 사건 기일 자동 등록 (QT-Q2)**
  - 사건에 개시결정일·채권자집회일·면책심문기일·보정 기한을 저장하면 캘린더 일정이 자동으로 생기고, 바뀌면 갱신·삭제. 일정에는 '사건에서 자동 생성' 표시.
  - 알림: G 트랙 예약 발송 스케줄러가 생기면 D-7·D-1 변호사 알림(사무소 설정), 의뢰인 안내 알림톡은 변호사가 켠 경우만.
- **📆 날짜 간격 계산 (새 도구)**
  - 두 날짜 사이 일·개월, '기준일로부터 1년 이내' 판정. 파산의 지급불능 시점 기준 처분재산·차용·편파변제 질문 기간(BK-4), 회생의 최근 대출 시점 확인에 사용.
- **💳 변제 회차 일정표 (새 도구)**
  - 개시결정일·첫 납입일·월 변제금·기간 → 회차별 납입일(주말·공휴일 표시)·누적 금액. 사건 연결 시 의뢰인 안내문·회생동행 납부 일정으로 보내기.

### 3-2. 계산·법원 실무

## 4. 디자인·UI 개선

- **이름 하나로:** '실무 퀵툴'만 사용(메뉴·창·설정·안내 문구). 'AI'처럼 보이는 반짝이 아이콘 대신 도구 아이콘.
- **배지 정리:** 마케팅형 배지 삭제, 필요한 것만 — '사건 연결됨', '○○년 기준', '파산용'.
- **크기:** 아이콘 버튼·칩·실행 버튼 최소 44px(데스크톱 마우스 환경도 36px 이상 + 넓은 클릭 영역), 결과 숫자는 16px 이상 굵게, 설명은 12px 이상 `text-slate-600` 이상(대비 AA).
- **결과 카드 공통 틀:** ① 핵심 결과 1줄(크게) ② 계산 근거 펼치기 ③ 기준(연도·법조문) ④ 행동 버튼(사건에 보내기 / 할 일·일정 / 메모 / 복사). 도구마다 다른 배치를 하나로.
- **복사 문구 머리:** 기본 '[내부 검토용] …'. 의뢰인용 문구는 별도 버튼 '의뢰인 안내문으로 복사'(감면율 제외, 금지어 검사 통과분만).
- **토큰:** 그림자는 `index.css` 토큰(`shadow-sm/md/lg`), 색은 브랜드 토큰(`brand`)으로, 반경 3단계 규칙.
- **빈 상태·오류:** 사건이 없을 때 "사건을 고르면 값이 채워져요 [사건 고르기]", 서버 저장 실패는 토스트 + 다시 시도.
- **채팅 연결:** 상담 채팅 머리의 '실무 퀵툴' 버튼을 실제로 연결(이미 있는 `onOpenQuickDock` 전달).
