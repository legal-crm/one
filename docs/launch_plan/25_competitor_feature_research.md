## 0. 한눈에 보는 결론

1. **우리 자리는 비어 있어요.** 국내 경쟁사는 소비자용 변호사 찾기(로톡)와 사무소용 서식·CRM(디던비·로패스·리걸프렌즈)으로 나뉘어 있고, 둘을 이은 곳이 없어요. 마이김변은 '의뢰인 유입(변호사 찾기) + 무료 사건 관리 + 의뢰인 화면'을 한곳에서 해요. 이 연결이 가장 큰 차별점이고, 무료라는 점만으로는 부족해요(디던비도 사건 2건까지 무료).
2. **시장은 커지고, 의뢰인의 선택지도 늘었어요.** 2026년 상반기 개인회생 신청 81,723건(전년 같은 기간보다 13.2% 증가), 신용회복위원회 개인 채무조정 신청 240,898건(19.3% 증가)이에요. 개인채무자보호법(2024-10 시행)으로 금융회사에 직접 채무조정을 요청할 수 있고, 새도약기금이 장기 연체 채권을 사들여 약 10만 8천 명의 추심을 끝내고 있어요. 의뢰인은 이제 "회생·파산 말고 다른 길은 없나"를 먼저 물어요.
3. **해외 경쟁사는 '처음부터 끝까지 한 흐름'으로 가고 있어요.** 의뢰인이 질문지를 직접 채우면 사무소가 검토해 사건으로 가져오고(NextChapter), 신용 보고서에서 채권자를 자동으로 불러오고, 법원 송달 문서를 자동으로 모아 할 일로 바꾸고, 기일 기준 자동 문자를 보내요. 우리 기획(H-14·CM·KT·FE)도 같은 방향인데, **채권자 정보 자동 수집**과 **채권자에게 보내는 문서 일괄 발송**이 비어 있어요.
4. **새로 제안한 기능 16개(NF-1~NF-16) 중 2개(NF-2·NF-6)는 사용자 결정으로 빠져 14개예요.** 출시 전은 5개예요.
   - NF-1 다른 제도 함께 안내
   - NF-4 채권자 일괄 발송(수임 통지·부채증명서 발급 요청)
   - NF-5 공용 채권자 정보(서버, 확인일 표시)
   - NF-10 다른 프로그램에서 옮겨오기
   - NF-11 첫 사용 안내·예시 사건
5. **만들지 않을 것도 정했어요.** 플랫폼이 상담료·수임료를 받아 넘기는 결제, 채무 감면 협상 대행, 실적·가격 비교, AI 전화 응대는 변호사법·광고 규정과 부딪혀요.

## 2. 시장·제도 흐름과 앞으로 필요할 것 (예측)

| 흐름 | 근거 | 그래서 필요한 것 |

**NF-10 다른 프로그램에서 옮겨오기** 🔴
- 무엇: 엑셀(의뢰인 이름·연락처·사건 유형·단계·사건번호·다음 기일) 올리기 → 열 맞추기 → 미리보기·중복 확인(CM-1 '같은 분인가요?') → 가져오기. 채권자는 디던비·로패스 CSV(회생 13열·파산 18열)를 읽어요.
- 왜: 우리는 무료지만 옮기는 수고가 크면 안 와요. 비공개 베타 변호사 3~5명이 첫 주에 바로 써야 해요.
- 규칙: 가져온 사건은 플랫폼 통계·LD-1 규칙에서 빼요(이관 사건과 같음). 개인정보 처리 주체는 사무소예요(처리방침 수탁 조항).
- 시스템: `import_jobs`(파일 지문·행 결과·되돌리기), `create_case`(CM-1) 재사용, SL 영업 DB 엑셀 가져오기와 같은 열 맞추기 부품.

**NF-11 첫 사용 안내·예시 사건** 🔴
- 무엇: 승인 직후 '예시 사건' 1건(예시 표시, 실제 사람 아님, 언제든 삭제)과 10분 둘러보기(사건 만들기 → 서류 요청 → 서식 미리보기 → 의뢰인 화면 보기). 사무소 설정 첫 단계(사무소 정보·직인·직원 초대) 확인 목록.
- 왜: NextChapter는 10분 안내를 내세워요. 우리 화면은 기능이 많아 첫인상이 어려워요.
- 규칙: 예시 사건은 통계·업무함 숫자·광고 지표에서 빼요(HM-1 시험 데이터 규칙과 같은 표시 칸).
- 시스템: `cases.is_sample`, 안내 진행 상태는 `user_preferences`(ST-2).

**NF-13 법원 송달 → 할 일 초안** 🟡
- 무엇: CM-7 법원 사건 조회에서 새 송달(보정권고·보정명령·기일 통지·개시결정 등)이 보이면 종류를 나눠 '확인 필요' 카드와 할 일 초안을 만들어요. 보정이면 CR 회차 등록 초안, 기일이면 일정 초안. 반영은 사람이 눌러요.
- 왜: NextChapter의 송달 자동 수집·분류가 사무소에서 가장 반응이 좋은 기능 중 하나예요.
- 시스템: CM-7 감지 결과에 송달 종류 분류(규칙 먼저, 애매하면 '종류 확인 필요'), CR-2·CM-3 초안 함수 재사용.

**NF-14 공공 서류 자동 발급** ⚪
- 무엇: 의뢰인이 본인 간편인증을 하면 소득금액증명·건강보험 자격득실·국민연금 가입내역·지방세 세목별 과세증명 등을 받아 사건 서류함에 넣어요.
- 왜: 접수본 10건(14 기획서)의 첨부 대부분이 공공 서류예요. 로패스도 '우리민원'에서 정보를 불러와요.
- 확인할 것: CODEF 상품별 요금·약관(A-5), 서류마다 법원 제출용으로 인정되는지(원본·발급번호), 개인정보 영향(본인 인증 정보를 저장하지 않음). 대시보드 배너의 '8대 공공기관' 문구는 이 기능이 생기기 전까지 지워요(HM).

## 8. 완료 기준
