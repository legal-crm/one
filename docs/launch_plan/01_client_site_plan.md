### 1-B. 상단 배너 (Hero 오른쪽 슬라이더)

- **결정 (10-24, C-Q3 = a):** Hero 오른쪽 슬라이더로 확정. Hero 위 띠 배너는 만들지 않아요.
- **위치·크기:** 데스크톱은 Hero 오른쪽 5칸(약 520×390px, 4:3). 태블릿 이하는 CTA 아래 전체 폭 16:9(모바일 약 343×193px). CTA를 밀어내지 않도록 **Hero 안**에 둬요.
- **슬라이드 종류**
  1. **브랜드 배너 (플랫폼 자체, 무료):** 스텔스 가명 소개, 이용 3단계, 회생동행, 서류 모바일 제출 등. 통합어드민 '콘텐츠 제어 > 메인 배너'에서 이미지·제목·링크 관리 (기존 `MainBanner` 활용, 링크 필드 추가)
  2. **메인 배너 광고 (유료, 기존 상품 '메인 배너 광고'):** 변호사·사무소 소재. 각 슬라이드에 '광고' 표시
- **노출 규칙:** 5초 자동 넘김, 마우스를 올리거나 키보드 포커스 시 멈춤, '움직임 줄이기' 설정 사용자는 자동 넘김 안 함, 이전/다음·일시정지 버튼(44px), 점 표시. 광고는 무작위 순서, 전체 슬라이드 중 광고 비율 상한(예: 절반)은 관리자 설정.
- **이미지 규격:** 1040×780 이상 WebP(용량 200KB 이하), 모바일용 별도 업로드 가능, 대체 텍스트 필수. 첫 슬라이드만 우선 로딩, 나머지는 지연 로딩.

### 1-C. 중간 변호사 소개 배너 (광고 상품)

- **목적:** 변호사 사진을 크게 보여 줘서 사이트가 사람 중심으로 보이게 하고, 광고 상품으로 판매해요.
- **위치:** 홈 5번(상황별 정보 다음). 이후 변호사 찾기 상단에도 같은 소재를 재사용할 수 있어요.
- **형태:** 가로 캐러셀. 데스크톱 한 화면에 3명, 모바일은 1.2명(다음 카드가 살짝 보여 넘길 수 있음을 알림). 카드 구성:
  - 변호사 **실사진**(3:4 세로, 상반신), 이름, 사무소명, 지역, 전문 분야 태그 최대 3개, 한 줄 소개(40자 이내)
  - 버튼: '프로필 보기' (변호사 찾기 프로필 모달), '상담 요청'은 기존 직접 선택 흐름으로
  - 카드 위 '광고' 표시, 섹션 아래 "변호사가 직접 등록한 유료 광고이며, 무작위 순서로 노출됩니다" 고지 (기존 문구 유지)
- **움직임:** 6초 자동 넘김, 카드 hover 시 사진 살짝 확대, 멈춤·이전/다음 버튼, '움직임 줄이기' 존중.
- **광고 규정 (마스터 4-1):** 결과 보장·성공률·수임 건수·'최고/1위' 같은 비교 표현 금지, 사무소명·광고 책임 변호사 표시, 사진은 변호사 본인 사진만(C-Q6), 승인된 변호사만.
- **누가 나오나 (10-24 결정, C-Q4 = b · C-Q5 = a)**
  - **광고 카드:** '메인 배너 광고' 또는 '상단 노출 광고'를 구매한 변호사는 이 배너에 **함께 노출**돼요(별도 상품 아님). 광고 카드끼리는 무작위 순서, 카드마다 '광고' 표시.
  - **등록 변호사 카드:** 광고 카드가 한 화면(데스크톱 3장)을 채우지 못하면, 남은 자리를 승인된 무료 등록 변호사로 채워요. 대상은 **실사진 프로필이 있는** 승인 변호사만, 무작위 순서, 카드에 '등록 변호사' 표시(광고와 글자·색으로 구분).
  - 순서: 광고 카드 → 등록 변호사 카드. 섹션 고지문은 광고만 있을 때 "유료 광고", 섞여 있을 때 "유료 광고와 등록 변호사가 함께 표시되며, 각각 무작위 순서로 노출됩니다"로 바꿔요.
  - 노출할 변호사가 한 명도 없으면 섹션을 숨겨요.
- **기존 코드 활용:** `ShowcaseAdSection`(DEV 전용, mock `adBanners`)을 실제 승인 소재를 읽는 캐러셀로 다시 만들어요. `AdBanner` 타입에 사무소명·지역·분야·사진 규격·승인 상태·노출 기간을 더해요.

### 1-E. 홈 전체 이미지·움직임 원칙

- **이미지 (10-24 결정, C-Q6):** 브랜드 일러스트·배너에 **AI 생성 이미지 사용 가능**. 상황별 카드 8종·이용 4단계·절차 다이어그램·브랜드 배너는 한 가지 그림체로 통일해요. 변호사 카드·배너의 얼굴 사진은 **변호사 본인 실사진**을 기본으로 해요(광고 규정상 본인 오인 방지). AI 이미지에는 의뢰인처럼 보이는 실사풍 인물을 넣지 않아요(후기·사례 오해 방지) — 일러스트풍 인물·사물·배경은 괜찮아요.
- **움직임:** 스크롤 시 섹션이 아래에서 살짝 떠오르는 효과(한 번만), 숫자 카운트 애니메이션은 쓰지 않아요(가짜 수치 오해). 모든 움직임은 `prefers-reduced-motion`에서 꺼요. 라이브러리는 이미 있는 `motion`만 사용.
- **성능:** 이미지 WebP·지연 로딩, 홈 전체 이미지 합계 1.5MB 이하 목표, 첫 화면 LCP 2.5초 이내.
- **접근성:** 슬라이더 정지 버튼, 대체 텍스트, 광고 표시를 글자로(색만으로 구분하지 않음).
