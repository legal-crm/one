### 1-G. 홈 '1분 변제금 계산기' (10-24 결정)

- **목적:** 이름·로그인 없이 바로 써 볼 수 있는 첫 방문 유입 장치. 계산기 자체는 고객 기획서 9번·개발 B-7의 '제도 이해용 계산기'와 **같은 엔진·같은 원칙**을 써요.
- **Hero:** 주 CTA는 '내 상황 체크하기' 하나로 유지. 아래에 텍스트 링크 "1분 변제금 계산해 보기 ↓" → 3번 섹션으로 부드럽게 스크롤. 계산기를 Hero에 직접 넣지 않아요(주 CTA 경쟁·Hero 규칙).
- **홈 3번 섹션 (빠른 모드)**
  - 입력 4개: 월 실수령 소득, 총 채무, 부양가족 수, 주거 형태(자가·전세·월세·무상). 모바일은 숫자 입력 + 슬라이더
  - 결과: **범위만** 표시(예: "월 약 70만~120만 원, 36~60개월"). 입력이 적어 범위가 넓고, "재산·주거비·세금 체납을 넣으면 범위가 좁아져요" 안내
  - 버튼 2개: '자세히 계산하기'(전체 계산기, 입력값 그대로 이어감) · '내 상황 체크하기로 이어서 정리'(입력값을 챗봇에 미리 채움)
  - 상담 요청·변호사 연결 버튼은 결과 옆에 두지 않아요. 고지문 "공개된 기준을 적용한 참고용 일반 계산이며, 개인 사건의 결과를 판단하지 않습니다"
- **챗봇 미리 채우기:** 사용자가 버튼을 누를 때만 **입력값**(소득·채무·부양가족·주거 형태)을 브라우저 안에서 챗봇에 넘겨요. 계산 결과 수치는 넘기지 않고, 챗봇 화면에도 결과 수치를 보이지 않아요(B-4). 서버 전송은 사용자가 챗봇을 끝내고 상담을 요청할 때 기존 흐름 그대로.
- **검색용 정적 페이지 `/calculator` (`public/calculator.html`, 신규)**
  - 내용: 계산 방법 설명(기준 중위소득 60% 생계비, 추가 생계비, 청산가치, 변제기간 3년 원칙·5년 이내와 3년 미만 단축 사유, 우선채권), 기준표 연도, 자주 묻는 질문 5~8개, "계산해 보기" 버튼 → 앱 계산기
  - 10-29 원문 확인 반영(27 기획서 10장): 설명에 근거를 함께 적어요 — 2027 기준 중위소득은 보건복지부고시 제2026-157호, 생계비는 '개시신청 당시' 기준(회생법원 실무준칙 제405호), 추가 생계비는 관할 법원 '생계비 검토 위원회 의결'(법원마다 조금 다름), 압류금지 예금 250만 원·보험 환급금 250만 원(민사집행법 시행령). 법원 이름을 들어 어느 법원이 유리하다고 쓰지 않아요.
  - `vercel.json` rewrite에 `/calculator` 추가, `sitemap.xml` 등록, 구조화 데이터(FAQ), 제목·설명 메타("개인회생 변제금 계산 방법과 참고용 계산기")
  - 기존 가이드 글(`public/guide/personal-rehabilitation.html` 등)에서 이 페이지로 연결
- **문구 원칙:** "내 월 변제금, 1분이면 대략적인 범위를 볼 수 있어요"처럼 범위·참고용을 드러내요. '탕감', '감면', '조정 가능성', '무조건' 같은 결과를 약속하는 표현은 쓰지 않아요.
- **측정 (L6):** 계산 시작 → 결과 확인 → '자세히 계산하기' / '내 상황 체크하기' 전환을 이벤트로 기록. 입력값 자체는 분석 도구로 보내지 않아요.
- **공개 순서:** B-3 통합 엔진, B-2 실제 접수 4건 대조, B-7 전체 계산기가 끝난 뒤 홈 섹션을 공개해요. 외부 변호사 검토(L4)에 **홈 배치·문구**까지 포함해요.
- **완료 기준:** 로그인 없이 홈에서 4개 입력 → 범위 표시까지 1분 이내, 같은 입력의 전체 계산기·통합 엔진 결과가 범위 안에 있음, 챗봇 미리 채우기 동작, 감면율·감면액·가능성 표현 0건, `/calculator` 정적 페이지가 검색엔진에서 읽힘(사이트맵 제출)

### 1-C. 중간 변호사 소개 배너 (광고 상품)

- **목적:** 변호사 사진을 크게 보여 줘서 사이트가 사람 중심으로 보이게 하고, 광고 상품으로 판매해요.
- **위치:** 홈 5번(상황별 정보 다음). 이후 변호사 찾기 상단에도 같은 소재를 재사용할 수 있어요.
- **형태:** 가로 캐러셀. 데스크톱 한 화면에 3명, 모바일은 1.2명(다음 카드가 살짝 보여 넘길 수 있음을 알림). 카드 구성:
  - 변호사 **실사진**(3:4 세로, 상반신), 이름, 사무소명, 지역, 전문 분야 태그 최대 3개, 한 줄 소개(40자 이내)
  - 버튼: '프로필 보기' (변호사 찾기 프로필 모달), '상담 요청'은 기존 직접 선택 흐름으로
  - 카드 위 '광고' 표시, 섹션 아래 "변호사가 직접 등록한 유료 광고이며, 무작위 순서로 노출됩니다" 고지 (기존 문구 유지)
- **움직임:** 6초 자동 넘김, 카드 hover 시 사진 살짝 확대, 멈춤·이전/다음 버튼, '움직임 줄이기' 존중.

### 1-E. 홈 전체 이미지·움직임 원칙

- **이미지 (10-24 결정, C-Q6):** 브랜드 일러스트·배너에 **AI 생성 이미지 사용 가능**. 상황별 카드 8종·이용 4단계·절차 다이어그램·브랜드 배너는 한 가지 그림체로 통일해요. 변호사 카드·배너의 얼굴 사진은 **변호사 본인 실사진**을 기본으로 해요(광고 규정상 본인 오인 방지). AI 이미지에는 의뢰인처럼 보이는 실사풍 인물을 넣지 않아요(후기·사례 오해 방지) — 일러스트풍 인물·사물·배경은 괜찮아요.

- **성능:** 이미지 WebP·지연 로딩, 홈 전체 이미지 합계 1.5MB 이하 목표, 첫 화면 LCP 2.5초 이내.
- **접근성:** 슬라이더 정지 버튼, 대체 텍스트, 광고 표시를 글자로(색만으로 구분하지 않음).

**서명·날인 방법 (이미 있는 기능 재사용)**
1. **전자계약 때 한 서명 다시 쓰기 (마이김변 계약 사건만):** 원격 서명(`ClientRemoteSignView`)에서 저장된 서명 이미지를 불러와요. 다른 문서에 쓰는 것이라 "이 서명을 면책신청서에 사용합니다" 동의를 받고 기록해요. 계약이 없는 이용자에게는 이 선택지를 숨기고 2~5번을 보여요.
2. **새로 서명:** 계약 서명과 같은 서명 패드(`SignaturePadModal` / `SignatureCanvas`)
3. **도장 만들기:** 변호사 직인 스튜디오(`lawyer/branding/SealStudioModal`)의 도장 생성 엔진을 의뢰인용으로 가져와 이름 원형 도장을 만들어요(실제 도장 질감 개선 E-3과 같이).
4. **내 도장 사진 쓰기:** 종이에 찍은 도장을 촬영하면 직인 스튜디오의 배경 제거(누끼) 기능으로 투명 도장 이미지를 만들어 넣어요.
5. (선택) **서명 칸 비워 두기:** 출력해서 직접 서명·날인할 때

만든 서명·도장은 서버에 저장해 다음 서류(진술서 등)에도 고를 수 있게 해요(S 원칙, 의뢰인 본인만 열람).

**출력·검증**
- 같은 데이터로 **PDF**(A4, 서명·도장 이미지 포함)와 **HWPX**(법원 원본 양식에 값 채움)를 만들어요 — H 트랙 빌더 재사용.
- 내려받기 전 검사: 필수 항목 누락, 사건번호 형식, 계좌번호 숫자, 서명·날인 방법 선택, 변제 완료 미확인 시 경고("변제를 마친 뒤 제출하세요" — 막지는 않음).
- 주민등록번호는 **저장하지 않아요**(L8). 출력할 때 입력 → 파일에만 들어가고 화면·서버에서는 지워져요. 다시 내려받으려면 다시 입력해요.
- 작성 내용(주민번호 제외)은 서버에 저장해 이어서 쓸 수 있어요.

**제출 안내 (마지막 화면)**
- 전자소송: 대법원 전자소송 사이트에서 사건 검색 → 서류 제출 → 내려받은 PDF 업로드
- 방문·우편: 출력해서 관할 법원 접수. 종이 접수는 출력본에 **자필 서명 또는 실물 도장 날인**을 권장(인쇄된 서명·도장 이미지 인정 여부는 법원마다 다를 수 있어요)
- 관할 법원마다 추가로 요구하는 서류가 있을 수 있다는 안내, 법원 연락처

**마이김변 변호사 사건만 (`mykim_lawyer`)**
- 첫 화면에서 "담당 변호사에게 접수 요청" 버튼을 함께 보여요. 누르면 작성한 내용이 변호사 CRM 6단계로 전달돼요(기존 '면책신청 요청하기'와 합침).
- 직접 작성·내려받기도 그대로 쓸 수 있어요 (D-Q1 결정). 의뢰인이 직접 내려받으면 담당 변호사 CRM(사건 6단계·오늘의 업무)에 "의뢰인이 면책신청서를 직접 내려받음" 알림이 가요. 이중 접수를 막기 위해서예요. 다운로드 직전에도 "담당 변호사가 접수하는 사건이면 먼저 변호사와 상의하세요" 안내를 보여요.
- 외부 사무소·나홀로 사건에는 이 버튼이 없어요(마이김변 CRM에 담당 변호사가 없음).

**바꿀 버튼**
- 회복 아카데미 '면책신청서 양식 내려받기' → **'면책신청서 작성하기'**

- 마이페이지 사건 진행 카드의 면책신청 영역: '직접 작성하기' + '변호사에게 접수 요청'
- 빈 양식 파일(`/forms/rehab-discharge-application.hwp`)은 작성기 마지막 화면에 '빈 양식만 받기'로 남겨요.

**범위:** 개인회생 면책신청서부터. 개인파산 면책신청서(`10.면책신청서.hwpx`)는 파산 절차가 달라 H 트랙 3묶음에서.

- **완료 기준:** 세 가지 출처(나홀로·외부 사무소·마이김변 변호사) 테스트 계정 각각으로 5단계를 마치면 모든 칸이 채워지고 서명(또는 도장)이 들어간 PDF·HWPX가 내려받아지고, 한글에서 열어도 서식이 깨지지 않아요. 회생동행 미등록 사용자도 직접 입력으로 완성할 수 있어요.
