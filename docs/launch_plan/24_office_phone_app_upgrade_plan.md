## 0. 한눈에 보는 결론 (10-29 AP-Q1~Q9 추천안대로 결정으로 개편 방향 확정)

1. **지금 기획은 '백그라운드 수집기 + 통화 앞뒤 알림'에 가까워요.** 통화·문자·녹음 수집, 통화 메모, 웹 → 업무폰 걸기, 영업 콜, 카톡 공유가 들어 있지만, 휴대폰으로 **일을 처리하는 화면**(오늘 할 일·기일·승인·서류 받기)은 없어요. 변호사·사무장이 법원·외근 중에 가장 많이 하는 일(기일 확인, 승인, 종이 서류 받기, 의뢰인 회신 확인)을 앱 안에 넣는 게 이번 업그레이드의 핵심이에요.
2. **배포 환경이 크게 바뀌었어요(기획 반영 필수).**
   - **안드로이드 개발자 인증:** 구글 인증 기기에서는 2026-09-30부터 일부 국가, **2027년부터 전 세계**에서 '인증된 개발자가 등록한 앱'만 일반 설치가 돼요. 미등록 앱은 사용자가 '고급 설치 절차'(1회 설정·재시작·24시간 대기)를 거쳐야 해요. → 출시 전에 **정식 배포 계정 등록·패키지 이름·서명 키 등록**을 해요. 무료 '제한 배포 계정'은 기기 20대 한도라 사무소 배포에 못 써요. [Android developer verification](https://developer.android.com/developer-verification), [FAQ](https://developer.android.com/developer-verification/guides/faq)
   - **문자 권한이 가장 큰 위험이에요.** 안드로이드 15부터 직접 설치한 앱은 문자 권한을 '제한된 설정 허용'을 따로 켜야 줄 수 있고, 구글 Play 프로텍트는 문자 읽기·받기·알림 접근·접근성 권한을 쓰는 직접 설치 앱을 '고위험'으로 보고 일부 국가에서는 **설치를 자동 차단**해요(국가별로 켜짐). 통화 기록 권한은 이 목록에 없어요. → **본 앱에서 문자·알림 접근 권한을 빼고, 별도 보조 앱으로 분리**해요(AP-Q2). [Play Protect 경고 안내](https://developers.google.com/android/play-protect/warning-dev-guidance), [제한된 설정](https://support.google.com/android/answer/12623953)
   - **삼성 '자동 차단'**은 승인된 스토어 밖의 앱 설치를 막아요 → 설치 안내에 '잠시 끄고 설치 → 다시 켜기'를 넣어요. 안드로이드 16은 통화 중에 민감한 설정 변경을 막아요 → 설치·권한 안내는 통화 중이 아닐 때.
3. **녹음은 계획대로 '휴대폰 기본 자동 녹음 파일'을 올리는 방식이 맞아요.** 안드로이드 10 이후 다른 앱의 통화 녹음은 막혀 있고, 삼성 갤럭시는 한국에서 기본 전화 앱 자동 녹음을 지원해요. 기종별 폴더를 진단 화면으로 확인하는 기존 설계를 유지해요. 삼성 기기 안 AI 대화록은 다른 앱이 읽을 수 없어 서버 대화록(CL-8)을 그대로 써요. [삼성 통화 녹음](https://www.samsung.com/us/support/answer/ANS10004613/)
4. **새 기능 묶음(우선순위 순):** ① 모바일 업무함·기일·승인(변호사 전용 일은 생체 인증으로) ② 종이 서류·법원 우편물 스캔(구글 문서 스캐너, 카메라 권한 없음) → 사건 서류함·보정 회차 등록 ③ 공용 회선 모드(사무실 상담 휴대폰을 여러 직원이 같이 씀) ④ 홈 화면 위젯·진행 알림 ⑤ 음성 메모(직접 누를 때만) ⑥ 발신자 정보 표시 개선. 복잡한 화면(사건 상세·서식·계약)은 웹을 브라우저 탭으로 열어요(웹뷰 금지 원칙 유지).
5. **시스템:** Kotlin·Compose 단일 코드, 모듈 분리, '보낼 목록(outbox) → 서버 멱등 처리' 동기화 엔진, 통화 끝남 즉시 작업(빠른 작업 할당량 안), 긴 업로드는 사용자 시작 전송 작업, 푸시는 '보이는 알림'만 높은 우선순위, 기기 토큰 회전·생체 잠금, 서버는 `api/device.js` 하나(버전 경로), 웹 '설정 › 업무폰'·통합어드민 '앱 배포' 관리.

## 3. 업그레이드 기능

### 3-1. 모바일 업무함·일정·승인 (AP-5)

- **홈 = 오늘 할 일:** HM 업무함(`office_work_queue`)의 '내 일' 중 휴대폰에서 끝낼 수 있는 것: 오늘·지난 기한, 부재 콜백, 영업 콜, 통화 메모 미작성, 등록 요청, 올리지 못한 녹음, 의뢰인 회신 도착(서류·보정 항목). 항목을 누르면 앱 화면(전화·메모·스캔) 또는 웹 해당 화면(브라우저 탭).
- **일정·기일:** 내 일정·사건 기일(T-5·CM-7 서버 데이터), 기일 전날·당일 알림(법원·법정·사건 가명), '기일 결과 남기기'(출석·연기·다음 기일·메모 → CM-3 `record_case_milestone`). 지도는 외부 지도 앱 링크만(위치 수집 안 함 — 위치정보법 신고 대상 피함).
- **승인함(변호사 전용 🔒, RB 결정):** 제안서 컨펌·계약 발송 승인·보정서 확정 요청 → 내용 요약 + '웹에서 자세히' + 승인/반려. 승인은 **생체 인증 다시 확인**(BiometricPrompt) 후 서버 기록. 직원 계정에는 메뉴 자체가 없음.
- **업무폰 기기 승인(대표):** 새 직원 기기 연결 요청을 휴대폰에서 승인(CL-2·RB-8).
- **상담 요청 알림:** 새 상담 요청·응답 기한 D-1(OP-6) → 요약(가명·지역·채무 구간) + '웹에서 검토'. 제안서 작성은 웹.

### 3-2. 서류·우편물 스캔 (AP-6)

- **종이 서류 스캔:** 사무실에 가져온 부채증명서·소득 서류 → 구글 문서 스캐너(자동 테두리·여러 쪽·PDF) → 사건 고르기(최근 사건·검색) → 서류 종류(DP 체크리스트 항목) → 업로드(SHA-256, CL-4 방식) → 3단계 서류함 '받음'. 개인정보 문서는 휴대폰 사진첩에 남기지 않음(앱 임시 폴더에서 업로드 후 삭제).
- **법원 우편물 스캔:** 보정권고·보정명령·개시결정 등 → '보정 회차 등록'(CR-2)·'결정 등록'(CM-3)으로 바로. 서버 OCR(인증 헤더 포함, 기존 401 문제 해결)로 송달일·기한·항목 초안 → 웹에서 확인. 자동 반영은 하지 않음(사람 확인).
- **QR 연결도 코드 스캐너로:** 앱 카메라 권한 삭제.

### 3-3. 공용 회선 모드 (AP-7, AP-Q4)

- 사무실 '상담 전화' 휴대폰 한 대를 여러 직원이 같이 쓰는 경우: 기기를 **사람이 아니라 회선(사무소)** 에 연결. 통화·문자 기록은 회선 기준으로 올리고, 통화 메모·결과 화면에서 '작성자'를 고르게(직원 PIN 4자리, 앱 잠금과 별도).
- 웹 소통 기록에 '회선: 상담 전화 1 · 메모 ○○'로 표시, 영업 콜 대기열은 회선 공용 + 사람별.
- 개인 휴대폰 모드(기존)와 기기 연결 때 선택. 공용 기기는 생체 잠금 대신 앱 PIN.

### 3-4. 홈 화면 위젯·진행 알림 (AP-11)

- **위젯(Jetpack Glance):** '오늘 기한 n · 콜백 n · 업로드 대기 n', 누르면 해당 목록. 이름·사건 정보 없음(잠금 화면·옆 사람 노출).
- **진행 알림:** 녹음 업로드 진행(안드로이드 16 진행 중심 알림, 이전 버전은 일반 진행 알림), 영업 콜 '3/12번째'.
- **알림 채널 정리:** 걸려 온 전화(우선), 통화 후 메모, 기한·일정, 승인 요청, 새 상담 요청, 업로드 상태(조용히), 앱 업데이트. 사람이 채널별로 끌 수 있고, 사무소 필수 채널(기기 해지 등)은 끌 수 없음.

### 3-5. 음성 메모 (AP-13, AP-Q7)

- 이동 중 '음성으로 메모' 버튼을 **직접 누르는 동안만** 녹음(마이크 권한, 통화 녹음 아님, 통화 중엔 버튼 숨김) → 서버 대화록(CL-8 경로) → 사건 메모 초안 → 본인이 확인 후 저장. 원본 음성은 메모 저장 후 30일 뒤 삭제(사무소 설정).
- 기존 '마이크 권한 없음' 원칙의 예외라 사무소 설정 기본 끔, 켤 때 권한 요청.

### 3-6. 발신자 정보 표시 개선 (AP-12, AP-Q6)

- 기본: 지금 기획대로 전화 상태 변경 → 번호 1건 조회 → 우선 알림.
- 선택: '통화 화면에 사건 정보 보기'를 켜면 발신자 정보 앱 역할(`CallScreeningService`) 요청 → 통화가 울리기 전에 번호를 받아 더 빨리 표시. 다른 발신자 앱(후후·T전화 등)과 동시에 못 쓴다는 안내. 차단·거절 기능은 쓰지 않음(모든 통화 그대로 통과).

### 3-7. 문자·알림 접근 보조 앱 (AP-2, AP-Q2)

- **본 앱('마이김변 업무폰'):** 통화 기록·전화 상태·오디오 파일·알림·인터넷·부팅 완료·연락처 쓰기(선택)·전송 작업만. **문자·알림 접근·접근성·다른 앱 위 그리기 권한 없음** → Play 프로텍트 고위험 판정·자동 차단·제한된 설정을 피함.
- **보조 앱('마이김변 업무폰 문자 연결', 선택 설치):** 문자 받기·읽기·보내기(CL-11), 알림 접근(KT-5 카톡 알림 보조 기록). 같은 서명 키, 본 앱과는 **서명 권한으로 보호된 연결로만** 통신(다른 앱이 붙을 수 없음), 서버와 직접 통신하지 않고 본 앱의 보낼 목록으로 넘김. 설치·'제한된 설정 허용' 단계 안내 화면.
- 보조 앱이 막히는 환경(자동 차단이 켜진 국가·기기)에서도 본 앱의 통화·녹음·업무 기능은 그대로 동작. 문자 기록이 없으면 웹 소통 기록에 '문자 연결 안 됨' 표시.

### 3-8. 오프라인·법원 대응 (AP-8)

- 법정 안·지하 등 통신이 약한 곳: 메모·기일 결과·스캔은 기기 안 보낼 목록(Room, 암호화)에 저장 → 연결되면 자동 전송, 홈 상태 카드에 '보낼 것 n건'.
- 일정·기일·오늘 할 일은 마지막 동기화본을 읽기 전용으로 보여 주고 '○분 전 기준' 표시.

### 3-9. 웹 화면을 여는 방식 (AP-Q3)

- 사건 상세·서식 작성·계약·제안서 작성 같은 복잡한 화면은 앱에 다시 만들지 않고 **Chrome 맞춤 탭**으로 `mykim.kr` 해당 주소를 열어요(웹뷰 아님, 브라우저 로그인 세션 사용). 앱 ↔ 웹 이동은 앱 링크(`https://mykim.kr/app/...` 도메인 확인 파일)로.
- 앱에 직접 만드는 화면은 '휴대폰에서 1~2분 안에 끝나는 일'만: 통화·메모·스캔·승인·기일 결과·영업 콜·설정.

### 4-2. 동기화 엔진 (AP-3)

```
[기기 이벤트] 통화 끝남·문자(보조 앱)·녹음 파일·메모·스캔·기일 결과
   → 보낼 목록(Room): 기기 기록 키(종류 + 기기 ID + 원본 ID + 시각) · 내용 · 상태
   → 업로드 작업(빠른 작업 → 실패 시 지수 대기, 네트워크 조건)
   → 서버 api/device.js: 기록 키로 멱등 처리(같은 키는 한 번만 저장) → 받은 키 목록 응답
   → 기기: 받은 키만 지움
[서버 → 기기] 연락처 해시·업무함·일정·정책 변경 = '바뀌었음' 푸시(보통 우선순위) → 앱이 변경분 요청(마지막 동기화 시각 기준)
             걸기·승인 요청·새 상담 요청 = 보이는 알림 푸시(높은 우선순위)
```

- 서버 기준 시계: 모든 기록에 기기 시각·서버 수신 시각, 2분 넘게 차이 나면 경고(기존 설계).
- 충돌: 메모·기일 결과는 '추가만'(수정은 새 버전), 서버가 같은 사건 기록을 웹에서 먼저 바꿨으면 기기 쪽은 새 버전으로 붙임.

### 4-3. 서버 (`api/device.js`, 함수 1개 안 경로)

| 경로(`/api/device/v1/...`) | 하는 일 |
|:---|:---|
| `pair/start`·`pair/confirm` | QR(웹 발급, 5분) → 기기 공개키 등록 → 대표 승인 대기 |
| `token/refresh` | 기기 토큰 30일 회전, 서명 확인 |
| `heartbeat` | 앱 버전·권한 상태·녹음 폴더 상태·대기 건수 → 최소 버전·정책·킬 스위치 응답 |
| `contacts/delta` | 사무소 번호 해시 변경분 |
| `events/batch` | 통화·문자·메모·기일 결과 묶음(멱등) |
| `recordings/init`·`complete` | 서명 업로드 주소·지문 확인 |
| `documents/init`·`complete` | 스캔·카톡 자료 업로드(사건·서류 항목 연결) |
| `queue`·`schedule` | 내 업무함·일정 변경분 |
| `approvals/{id}/decide` | 승인·반려(생체 확인 표시·기기 서명 포함, 🔒 변호사 계정만) |
| `commands/ack` | 걸기·문자 명령 결과 |
| `lookup` | 걸려 온 번호 1건 조회(2초 제한) |
| `logs/upload` | 진단 정보(개인정보 제외, 사용자 동의) |

- 인증: 기기 토큰(사람·사무소·기기 연결) + 요청 서명(Keystore 키) + 사무소 RLS(RB-1). 관리자(통합어드민)는 기기 상태 숫자만 봄(제로날리지).
- 테이블: `office_devices`(모드 개인/공용·회선·권한 상태·버전), `device_tokens`, `device_events`(멱등 키), `device_commands`, `device_app_releases`(통합어드민), 기존 CL-1 표들.

### 4-4. 보안 (AP-4)

- 앱 잠금: 생체 또는 화면 잠금 확인, 5분 무활동 후 다시(사무소 정책으로 1~15분). 공용 모드는 앱 PIN.
- 화면 캡처·최근 앱 미리보기 가리기(사건·메모 화면 `FLAG_SECURE`).
- 루팅·변조 기기: 구글 Play Integrity의 **기기 판정**으로 연결 차단(설치 출처 판정은 직접 설치라 쓰지 않음). 판정이 안 되는 기기는 사무소 정책 '경고만/막기'.
- 원격: 해지 → 다음 접속 때 토큰·보낼 목록·캐시·연락처 해시 삭제, '분실' 해지는 FCM으로 즉시 삭제 명령.
- 권한 최소: 본 앱은 통화 기록·전화 상태·오디오 파일·알림·연락처 쓰기(선택)·마이크(음성 메모를 켤 때만)·인터넷·부팅 완료. 카메라·문자·알림 접근·접근성·오버레이·통화 걸기 권한 없음.
- 백업 끔, 외부 공개 구성 요소 없음(공유 받기 화면만, 받은 파일은 앱 임시 폴더), 릴리스 난독화.

### 4-5. 배포·업데이트 (AP-1·AP-9)

- **개발자 인증:** 안드로이드 개발자 콘솔 정식 배포 계정(신원 확인·25달러), 패키지 `kr.mykim.office`·`kr.mykim.office.sms` 등록, 서명 키 등록. 조직 등록이면 D-U-N-S 먼저(최대 28일) — 개인사업자 발급 가능 여부 확인(AP-Q1).
- **설치 파일 배포:** 통합어드민 '앱 배포'(`device_app_releases`: 버전·파일 지문·최소 지원 버전·변경 내용·단계 배포 비율) → 웹 '설정 › 업무폰'에서 로그인한 사무소만 내려받기(짧은 서명 주소).
- **앱 안 업데이트:** 하트비트가 새 버전 알림 → 앱이 내려받아 지문·서명 확인 → 설치 화면(설치 권한 '이 출처 허용' 1회). 최소 버전 미만이면 업로드 멈추고 업데이트 요구(보낼 목록은 보관). 단계 배포(10% → 50% → 100%)와 문제 버전 되돌리기.
- **설치 안내(웹 + PDF):** 출처를 알 수 없는 앱 허용 → 삼성 자동 차단 잠시 끄기 → Play 프로텍트 경고 대처 → 설치 → 자동 차단 다시 켜기 → 처음 설정 5단계. 보조 앱은 '제한된 설정 허용' 화면까지.
- **회사 지급폰(선택, ⚪):** 안드로이드 엔터프라이즈(업무 프로필·완전 관리)로 배포하면 인증·자동 차단 문제가 줄지만 관리 도구 설정이 필요 → 출시 후 큰 사무소 요청 때 검토.

### 4-6. 시험 (AP-15)

- **기기 목록:** 갤럭시 S·A 시리즈(One UI 6·7·8), 안드로이드 13·14·15·16·17, 픽셀 1대, 듀얼 SIM 1대, 저가형 1대.
- **시나리오:** 11 기획서 8장 완료 기준 + 강제 종료·재부팅·비행기 모드·절전(삼성 '절전 예외' 해제 상태)·데이터 절약·SIM 2개·업데이트 중 통화·공용 모드 작성자 바꾸기·보조 앱 없음·Play 프로텍트 경고·자동 차단 켜짐.
- **자동화:** 단위·동기화 엔진 시험(가짜 서버), 화면 시험(Compose), 릴리스 전 실기기 점검표.

## 8. 완료 기준

- 새 갤럭시 휴대폰에 설치 안내대로 따라 하면 Play 프로텍트·삼성 자동 차단 단계를 거쳐 10분 안에 연결이 끝나고, 앱 정보에 '인증된 개발자(몬스터랩 또는 대표)'가 보여요.
- 본 앱 권한 목록에 문자·알림 접근·접근성·카메라·오버레이·통화 걸기가 없어요. 보조 앱을 설치하지 않아도 통화·녹음·업무함·스캔이 모두 동작해요.
- 등록 의뢰인과 통화 후 2분 안에 웹 소통 기록·녹음이 보이고(11 기획서 8장), 같은 통화가 두 번 올라가지 않아요(멱등).
- 비행기 모드에서 남긴 메모·기일 결과·스캔이 연결 뒤 자동으로 올라가요.
- 변호사가 휴대폰에서 제안서 컨펌을 승인하면 생체 인증을 다시 묻고, 서버 기록에 '업무폰·생체 확인'이 남아요. 직원 계정에는 승인함이 없어요.
- 부채증명서를 스캔해 사건에 올리면 3단계 체크리스트가 '받음'이 되고, 휴대폰 사진첩에 파일이 남지 않아요. 보정권고를 스캔하면 웹에 회차 초안(송달일·기한·항목)이 생기고 사람이 확인해야 확정돼요.
- 공용 모드 휴대폰에서 직원 두 명이 번갈아 메모를 남기면 웹에 작성자가 맞게 표시돼요.
- 해지(분실)하면 1분 안에 앱 데이터가 지워지고 다음 접속이 거절돼요. 루팅 기기는 연결이 막혀요(정책이 '막기'일 때).
- 통합어드민에서 새 버전을 10%에 배포하면 해당 기기만 업데이트 알림을 받고, 되돌리면 알림이 멈춰요.
