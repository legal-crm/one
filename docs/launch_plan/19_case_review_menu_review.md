## 0. 결론 (의견 → 10-29 CV-Q1 결정으로 확정)

**따로 둘 이유가 약해요. 사이드바 메뉴는 없애고, 기능은 '사건 검토' 패널 하나로 만들어 상담 요청 화면과 사건 관리 1단계에 넣는 걸 권해요.**

이유:

1. **목록이 '상담 요청' 목록과 같아요.** 이 화면의 표는 의뢰인이 아니라 상담 요청 한 건이 한 줄이에요. 그래서 같은 의뢰인 '파란 문방울 62'가 3번 나오고, "5명 등록된 의뢰인"은 사람 수가 아니라 요청 수예요. 같은 요청 목록은 이미 '상담 요청' 메뉴에 있어요.
2. **사이드바 숫자도 이 화면 숫자가 아니에요.** 배지 '1'은 "아직 제안서를 안 보낸 새 요청 수"로, '상담 요청' 배지와 같은 값이에요. 목록(5건)과 기준이 달라요.
3. **'AI'가 없어요.** 외부 AI(Gemini 등) 호출이 0건이고, 전부 규칙과 계산이에요. 'AI가 자동 검토' 'AI 자동 분석'은 사실과 달라요. 이름이 기능보다 크게 들려서 따로 메뉴가 필요한 것처럼 보일 뿐이에요.
4. **저장되는 게 없어요.** 검토 상태·시나리오 선택·플랜 조정·변호사 컨펌 요청이 화면 메모리에만 있어 새로고침하면 사라져요. 남는 건 기록(감사 로그)뿐이에요. 검토 의견·승인·발송 버튼의 처리 함수 7개는 화면에 연결되지 않은 죽은 코드예요.
5. **사건과 끊겨 있어요.** 수임 뒤 사건 관리에 쌓이는 채권자 목록·부채증명·변제계획을 안 읽고 상담 요청 때 입력값만 봐요. 사건으로 가는 버튼도, 사건에서 오는 버튼도 없어요(유일한 진입 버튼은 화면에서 닿을 수 없는 '신규 리드' 보기에 있어요).
6. **같은 일을 하는 화면이 이미 셋이에요.** 사건 관리 1단계에 **같은 이름 'AI 사건 분석'** 섹션(고정 문장 총평 + 위험 3칸), 상담 요청 상세에 'AI 정밀 검토' 탭(고정 문장 "우량 적격 사례"), 채팅 옆 패널·사건 옆 패널의 탕감률·DTI(정의가 서로 다름). 숫자 계산도 엔진 두 개를 섞어 써요.
7. **유료 잠금 이유도 사라졌어요.** 10-24 LA-Q1에서 'AI 사건 분석 무료 개방'으로 정했어요. 잠긴 상품이라 메뉴를 따로 둔 것인데, 무료가 되면 메뉴를 나눌 이유가 없어요. 나중에 유료로 바꾸더라도 과금 모드는 기능(패널) 단위로 걸면 돼요.

**남길 가치가 있는 것:** 사실 정리 엔진(`factEngine`)·검토 규칙 엔진(`reviewRuleEngine`), 분석 부품 6개(특수 채권자, 면제 재산, 담보·질권, 인가 요건 확인, 변제 시나리오, 관할 참고), 사무소 검토 기준(규칙) 관리, 제안서에 분석 근거를 붙이는 기능. 이건 "사건을 보면서 쓰는 도구"라 사건 옆에 있어야 쓰기 좋아요.

**메뉴를 따로 두자는 쪽의 논리와 판단:** "분석할 건만 모아 보는 작업 목록"이 필요하다는 주장은 가능해요. 그런데 그 목록은 '상담 요청'(새 요청·검토 중·제안 발송) 화면이 이미 하고 있고, 업무함(HM-3)이 '제안서 작성 대기'를 모아 보여 줄 예정이라 중복이에요.

### 2-1. 사건 검토 패널 (CV-1)

- 지금 상세 화면을 `CaseReviewPanel` 하나로 정리해요. 입력은 **사건 번호**만 받고, 사건 관리에 자료가 있으면 그걸 먼저, 없으면 상담 요청 입력값을 읽어요(출처 표시: "의뢰인 입력값" / "사무소 확인값").
- 구성: ① 사실 정리(채무·소득·재산·가족, 빈칸은 '확인 필요') ② 쟁점·위험(사무소 검토 기준 적용) ③ 변제 시나리오(안 A·B·C, B-3 통합 엔진) ④ 인가 요건 확인(청산가치·최저 변제액·기간) ⑤ 특수 채권자·면제 재산·담보 ⑥ 관할 참고 ⑦ 변호사 메모. 오른쪽 '의뢰인 입력 원본'은 접어서 열기.
- 계산은 B-3 통합 엔진 하나만. 기본값으로 빈칸 채우기(나이 40·남성·서울·급여) 금지 → '확인 필요'.
- **검토 기록 서버 저장**(`case_reviews`: 사건, 입력 스냅샷, 결과, 선택한 시나리오, 메모, 작성자·시각, 상태 초안/검토 요청/확인됨). 다시 열면 지난 검토가 보이고, 입력이 바뀌면 "자료가 바뀌었어요, 다시 검토" 표시.

### 2-2. 넣을 자리 (CV-2)

- **상담 요청 상세:** 지금 'AI 정밀 검토' 탭 → '사건 검토' 탭에 패널. 제안서 발송 전 판단용. 연락처 공개 전엔 가명·연락처 가림(상담 요청 화면 규칙 그대로).
- **사건 관리 1단계:** 하위 메뉴 'AI 사건 분석' → '사건 검토'에 같은 패널. 고정 문장 총평("회생 신청에 적합한 조건을 갖추고…")은 삭제.
- **수임 뒤(3~5단계):** 패널을 따로 두지 않고, 변제계획 편집기(B-3·B-6)가 같은 엔진을 써요. 1단계 검토 기록은 사건 기록에 남아 나중에 비교할 수 있어요.
- **파산 사건:** 회생 전용 계산을 보여 주지 않고 파산용 사실 정리·쟁점(BK-4 자료)만. 지금은 '개인회생' 고정.

### 2-3. 메뉴·진입 정리 (CV-3)

- 사이드바·모바일 더보기에서 'AI 사건 분석' 삭제, 탭 권한표 `case-copilot` 삭제.
- 예전 주소 `?tab=case-copilot`은 '상담 요청'으로 보내고 안내 한 줄. 알림 'copilot_review'는 그 사건 1단계 '사건 검토'로 열기.
- 업무함(HM-3)에 '제안서 작성 대기'(검토 안 한 새 요청) 항목.

### 2-5. 검토 기준 (CV-5)

- '기준 관리' → 설정 > 법률 기준 & 데이터 > **'사건 검토 기준'**. 서버 저장(사무소 단위), 대표·담당 변호사만 수정, 버전 기록. **분석이 실제로 이 기준을 쓰게** 고치고, 관할 참고도 이 기준에서 읽어요.

### 2-6. 제안서·컨펌 (CV-6)

- 제안서 작성은 `ProposalWorkspace` 하나로(상담 요청 화면의 자체 입력 폼·기본 탕감률 65%·고정 소견 문장 삭제). 사건 검토 기록이 있으면 근거를 자동으로 붙여 '변호사 검토 제안서(상세 분석 포함)'(RP-Q2)가 어느 경로에서든 만들어져요.
- 직원 컨펌 요청은 RB-6 `proposal_reviews`(서버) 하나로.
- 죽은 코드(검토 의견·체크리스트·승인·발송·반려·추가 확인 처리 함수와 상태), 쓰지 않는 import, `_backup_RehabReportModal_logic.ts` 삭제.

### 2-7. 과금 모드·유료 흔적 (CV-7)

- LA-Q1 결정대로 무료. 통합어드민 '부가 기능 과금 모드'(03 기획서 15장)의 대상 기능 이름을 'AI 사건 분석' → '사건 검토(상세 분석 제안서 포함)'로. 잠금 화면(`AICaseAnalysisLocked`)은 과금 모드가 '유료'일 때만 패널 자리에 나오게.
- 시드 메모 '프리미엄 플랜 가입 (월 30만원)'·'AI 사건 정밀 분석 솔루션 도입 (프리미엄)' 삭제, 의뢰인 화면 'AI premium' 표시 삭제(의뢰인에게 변호사 등급처럼 보임).

### 2-8. 개인정보·권한 (CV-8)

- 패널은 내가 맡은(또는 나를 고른) 요청·사건만. 같은 사무소 다른 변호사에게 온 요청은 사무소 권한(RB-1·RB-4) 범위로, 공개 요청 분기는 A-6과 함께 삭제.
- 연락처·실명은 연락처 공개 전 가림, 기록(감사 로그)의 브라우저 사본(무한 누적, 월 변제금·탕감률 포함) 삭제 → 서버만.
- 권한: 보기 = 대표·담당 변호사·사무장·상담 직원(배정 범위), 검토 기준 수정 = 대표·담당 변호사, 제안서 발송 = 변호사 전용(🔒, RB-Q4).

## 5. 완료 기준

- 사이드바·모바일에 'AI 사건 분석'이 없고, 예전 주소·알림으로 들어오면 해당 사건 '사건 검토'(또는 상담 요청)로 열려요.
- 상담 요청 상세와 사건 1단계의 '사건 검토'가 같은 숫자를 보여 주고, 채팅 옆·사건 옆 패널 숫자와 같아요(엔진 하나).
- 검토 결과를 저장하면 다른 기기에서도 보이고, 입력이 바뀌면 '다시 검토' 표시가 떠요.
- 사무소 검토 기준을 바꾸면 쟁점 결과가 바뀌어요.
- 어느 경로로 쓴 제안서든 검토 기록이 있으면 '상세 분석 포함'이 돼요. 직원 컨펌 요청이 대표 화면에 남아요.
- 연락처 공개 전에는 실명·연락처가 안 보여요.
- 변호사 화면에 'AI 자동'·'추천 표준안'·'신청 적격'·'우량 적격'·'전담상담'·'최대 탕감율' 0건. 의뢰인 화면 'AI premium' 0건.
