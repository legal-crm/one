## 0. 한눈에 보는 결론

1. **카카오는 개인 카카오톡 계정으로 보내고 받는 공개 API를 주지 않아요.** 기업이 프로그램으로 카카오톡을 보내는 공식 길은 카카오톡 채널을 통한 비즈메시지(알림톡·브랜드 메시지)와 상담톡(채널 1:1 채팅, 공식 딜러 경유)뿐이에요. 개인 계정으로 보내는 엑셀 프로그램은 PC 카카오톡 화면을 사람 대신 조작하는 매크로라 공식 기능이 아니에요.
2. **기본은 '한 번 누르는 반자동'이에요.** 마이김변이 보낼 글·파일을 준비하고 → 사무장이 업무폰에서 '카카오톡으로 보내기'를 누르면 카카오톡 공유 화면이 열리고 → 의뢰인 대화방을 골라 보내요. 무엇을 언제 누가 보냈는지는 마이김변에 기록돼요. **여러 명에게 한꺼번에 보내야 할 때는 사용자 제공 엑셀 프로그램 방식(PC 카카오톡 자동 조작)을 사무소가 켜는 선택 기능으로 붙일 수 있어요(KT-8, 운영자 판단).**
3. **받은 자료와 대화는 '공유'와 '대화 내보내기'로 백업해요.** 의뢰인이 카카오톡으로 보낸 사진·PDF는 카카오톡에서 '공유 → 마이김변 업무폰'으로 바로 사건 서류함에 넣어요. 대화 전체는 카카오톡 공식 기능 '대화 내보내기' 파일을 업무폰으로 공유해 사건 소통 기록에 올리고 전자지문을 남겨요. 실시간 자동 백업은 알림 읽기로 일부만 가능하고 빈틈이 커서 보조 기능(선택)으로만 둬요.
4. **알림톡 대체는 '발송 방법' 선택으로 넣되, 기한·금액이 걸린 안내는 알림톡을 유지하는 걸 권해요.** 알림톡은 팝빌이 발송 결과(성공·실패·대체 문자)를 돌려줘 '보냈다'는 근거가 남지만, 담당자 카카오톡은 받았는지·읽었는지를 마이김변이 확인할 수 없어요. 서류 요청·진행 안내처럼 응답을 끌어내는 안내는 담당자 카카오톡으로 바꾸고, 기일·보정 기한·납부·계약은 알림톡을 기본으로 두고 카카오톡을 함께 보낼 수 있게 해요.
5. **장기적으로 가장 깔끔한 방법은 사무소별 카카오톡 채널 + 상담톡 연동이에요.** 의뢰인이 사무소 채널을 친구로 추가하면 사무장 여러 명이 같은 대화방에서 응대하고, 주고받은 메시지·파일 전부가 서버에 남고, 담당자가 퇴사해도 기록이 사무소에 남아요. 딜러 계약·비용 확인이 필요해 출시 후로 둬요.

## 2. 담당자 카카오톡 보내기 (반자동, KT-1)

### 2-1. 업무폰 앱 흐름

```
[웹 또는 업무폰] 사건 → '카카오톡 보내기' (또는 알림톡 단계에서 '담당자 카카오톡' 선택)
  → 보낼 글(안내문 문구함 템플릿 + 변수 치환, 금지 표현 검사 통과) + 첨부(선택)
  → 담당 사무장 업무폰에 할 일 알림 "○○(가명)님께 카톡 보내기 · 서류 요청 안내 · 오늘 15시까지"
[업무폰] 알림 열기 → 미리보기 → [카카오톡으로 보내기]
  → 안드로이드 공유 → 카카오톡 앱 → 친구·대화방 고르기 (앱이 '의뢰인 카톡 이름' 메모를 위에 보여 줌)
  → 전송 → 업무폰으로 돌아오면 "보냈어요 / 못 보냈어요(사유)" 확인
  → 서버 기록: 채널 '담당자 카카오톡', 내용 지문, 첨부 지문, 담당자, 시각, 수신 확인 '알 수 없음'
```

- **대화방 바로 열기는 안 돼요.** 카카오톡은 전화번호로 특정 1:1 대화방을 여는 공개 방법이 없어 사무장이 공유 화면에서 직접 골라야 해요. 그래서 사건마다 **'의뢰인 카톡 이름'**(사무장이 카카오톡에서 보이는 이름)을 한 번 적어 두고 공유 직전에 크게 보여 줘 잘못 보내기를 막아요.
- **글만 보낼 때:** 안드로이드 공유(글). **파일:** 공유(파일) — 다만 사건 서류 원본(신분증 사본·통장 내역 등)은 카카오톡 서버에 남고 보관 기간이 지나면 만료되니, 기본은 **마이김변 보안 링크**(로그인 후 열람)로 보내고 파일 첨부는 사무소 설정으로 허용해요.
- **링크 카드:** 카카오 '카카오톡 공유' API(마이김변 카카오 앱에 메시지 템플릿 등록)로 "서류 제출하기 / 제안서 보기" 버튼이 있는 카드를 보내요(KT-7, 출시 직후). 카드에 개인정보·금액은 넣지 않아요.
- **PC에서:** 웹 '카카오톡 보내기' → '글 복사 + 보낸 것으로 기록' 버튼(PC 카카오톡에 붙여 넣는 건 사람이). 같은 기록을 남겨요.
- **의뢰인 연락처 저장(선택, KT-Q5):** 카카오톡은 휴대폰 연락처에 있는 번호를 친구로 자동 추가하므로, 업무폰 앱이 의뢰인 번호를 '가명 · 마이김변' 이름으로 연락처에 넣어 줄 수 있어요(연락처 쓰기 권한, 의뢰인이 '전화번호로 친구 추가'를 허용했을 때만 친구가 됨). 사건 종결·기기 해지 시 지워요.

### 2-2. 알림톡 단계·설정에 '발송 방법' 넣기 (KT-2)

지금 알림톡은 단계 변경(`triggerAlimtokOnStatusChange`, 6개 단계), 계약 체결(`ContractConversionModal`), 서류 요청(`CrmTab` 2613), 수임료 안내(`FeeAlimtokModal`), 알림톡 확인 창(`AlimtalkSendConfirmModal`)에서 팝빌로 나가요.

| 설정 | 내용 |
|:---|:---|
| 단계별 발송 방법 (사무소 설정) | ① 알림톡 ② 담당자 카카오톡 ③ 알림톡 + 담당자 카카오톡 ④ 보내지 않음 |
| 담당자 | 사건 담당 사무장(직원 권한), 없으면 대표가 지정 |
| 처리 기한 | 담당자 카카오톡이 기한(기본 3시간, 근무 시간 기준) 안에 '보냈어요'가 안 되면 **알림톡으로 자동 대체** (켜고 끄기) |
| 기본값 (KT-Q1 결정) | 상담 일정·서류 요청·서류 보완·진행 안내 = **②**, 계약 체결·기일(개시결정·채권자집회·면책심문)·보정 기한·수임료 납부·연체 = **③**(알림톡이 근거, 카톡은 친근한 보충) |
| 문구 | 같은 안내문 문구함(T-6)에서 '알림톡용(승인 템플릿)'·'카톡용(자유 문장)' 두 벌. 카톡용도 금지 표현 검사(M-9) |
| 발송 금지 시간 | 카톡·문자는 21시~8시 보내지 않음(할 일은 다음 날 8시로) |
| 기록 | 소통 기록 타임라인에 '알림톡(발송 결과)'·'담당자 카톡(담당자 확인)' 구분 표시 |

- **오픈율:** 담당자 카카오톡이 더 잘 읽힐 수 있다는 기대는 합리적이지만, 카카오는 개인 메시지 읽음 여부를 외부에 주지 않고 알림톡도 팝빌이 읽음 여부를 주지 않아 오픈율 자체는 잴 수 없어요. 대신 **'안내 후 의뢰인 행동까지 걸린 시간'**(서류 제출·답장·납부)을 채널별로 비교하는 지표를 사무소 통계에 넣어요(⚪).
- **비용:** 알림톡은 건당 요금(팝빌), 담당자 카톡은 무료지만 사무장 시간이 들어요. 할 일 묶음 처리(오늘 보낼 카톡 목록 → 차례로 공유)로 시간을 줄여요.

## 3. 카카오톡으로 받은 자료 넣기 (KT-3)

- 업무폰 앱을 안드로이드 **공유 대상**으로 등록 → 카카오톡에서 사진·PDF·문서·글을 길게 누르고 '공유 → 마이김변 업무폰'.
- 앱이 사건 고르기(최근 사건 5개 + 검색, 의뢰인 카톡 이름으로 추천) → 서류 종류 고르기(서류 체크리스트 항목과 연결) → 업로드(기기 SHA-256 + 서버 재계산, CL-4와 같은 방식).
- 사건 서류함에 '출처: 카카오톡(담당자 ○○, 받은 날짜)'로 들어가고, 3단계 서류 체크리스트가 '받음'으로 바뀌어요. 원본 파일 그대로 저장(압축·변환 안 함).
- 여러 장을 한 번에 공유하면 한 묶음으로.

## 4. 카카오톡 대화 백업

### 4-1. 기본: 대화 내보내기 (KT-4)

```
카카오톡 대화방 → 메뉴(≡) → 설정 → 대화 내용 내보내기 → '텍스트만 보내기' (사진·동영상은 '모든 메시지 내부저장소에 저장')
  → 공유 → 마이김변 업무폰 → 사건 선택 → 업로드
  → 서버: 원본 파일 보관 + 전자지문 → 줄 단위로 나눠(날짜·시각·보낸 사람·내용) 소통 기록에 '카카오톡' 채널로 표시
  → 같은 대화방을 다시 올리면 이미 있는 줄은 건너뛰고 새 줄만 추가(줄 지문으로 비교), 원본 파일은 회차별로 모두 보관
```

- **보낸 사람 맞추기:** 처음 한 번 "이 이름이 의뢰인, 이 이름이 우리 사무소"를 고르면 이후 자동.
- **주기:** 사무소 설정 '카톡 백업 알림'(기본: 주 1회 + 단계가 바뀔 때). 업무폰 할 일로 "○○님 카톡 대화 백업" 표시.
- **형식 변화 대비:** 카카오톡 버전·안드로이드/PC/아이폰마다 내보내기 글 형식이 달라 해석기를 여러 형식으로 시험하고, 해석 못 한 줄은 원문 그대로 보관해요(원본 파일이 기준).
- **PC 카카오톡:** PC에서도 '대화 내보내기' 후 웹 사건 화면에 파일 올리기로 같은 처리.

### 4-2. 선택: 알림 읽기 실시간 기록 (KT-5)

- 업무폰 앱에 '알림 접근' 권한(사용자가 설정에서 직접 켜야 함)을 주면 카카오톡 알림이 올 때 **대화방 이름·보낸 사람 표시 이름·글**을 읽을 수 있어요.
- 사건에 연결해 둔 대화방(의뢰인 카톡 이름)만 기기 안에서 골라 올리고, 나머지 알림은 저장·전송하지 않고 버려요.
- 빈틈: 사무장이 보낸 메시지, 대화방을 열어 두고 읽은 메시지(알림이 안 뜸), 사진·파일 원본(알림엔 '사진을 보냈습니다'만), 수정·삭제, 긴 글 잘림, 알림을 끈 대화방. 그래서 소통 기록에 **'알림 기준 보조 기록'**으로 표시하고, 대화 내보내기가 올라오면 같은 줄은 내보내기 쪽으로 바꿔요.
- 권장: 출시 때는 끄고(KT-Q3), 원하는 사무소만 켜는 기능으로 출시 직후.

### 4-3. 근거 자료로 쓸 때

- 카카오톡 대화는 소송에서 증거로 자주 쓰이고, 보통 원래 휴대폰 화면·내보내기 파일·캡처로 내요. 마이김변이 보장하는 것은 **"이 파일이 언제 올라왔고, 그 뒤로 바뀌지 않았다"**(전자지문·업로드 시각·올린 사람)까지예요. 카카오톡 원본 자체의 진위는 원래 휴대폰이 기준이라 **업무폰의 대화방을 지우지 않도록** 안내해요.
- 증빙 내보내기(CL-10)에 카카오톡 원본 파일·줄 목록 PDF·지문 목록을 함께 넣어요.
- 통화 녹음과 같이, 내보낸 줄 목록은 업무 참고용이고 원본 파일이 기준이에요.

## 5. 사무소 카카오톡 채널 + 상담톡 (출시 후, KT-6)

- 사무소마다 카카오톡 채널(무료 개설, 비즈니스 인증) → 카카오 공식 상담톡 딜러와 연동 → 마이김변 '소통 기록' 화면에서 채널 이름으로 1:1 채팅, 파일 주고받기, 여러 담당자, 응대 배정은 사무소 안에서만.
- 의뢰인이 채널을 친구 추가하거나 먼저 말을 걸어야 대화가 열려요. 알림톡에 '채널 추가' 버튼을 넣어 연결을 유도해요.
- 모든 메시지·파일이 서버에 들어오므로 백업·증빙 문제가 사라지고, 담당자가 바뀌거나 퇴사해도 대화가 사무소에 남아요.
- 해야 할 일: 딜러 2~3곳 비교(연동 방식·건당 요금·여러 사무소 채널을 한 계약으로 묶을 수 있는지), 채널 관리자 앱과의 동시 사용, 처리방침 수탁자 추가.
- 사무소별 채널이 기본이에요. 마이김변 채널 하나로 여러 사무소 상담을 받는 구조는 '플랫폼이 상담을 받아 사무소에 넘기는' 모양이 돼 알선 금지(제34조)와 충돌할 수 있어 쓰지 않아요.

## 8. 개발 트랙 KT

**🔴 출시 전**
- **KT-1 담당자 카카오톡 보내기(반자동):** 업무폰 공유 보내기·확인, 웹 '복사 + 기록', 의뢰인 카톡 이름, 보안 링크 기본, 기록(내용·첨부 지문·담당자·시각).
- **KT-2 알림톡 발송 방법 설정:** 단계별 ①~④, 담당자 할 일·기한·알림톡 자동 대체(G-1 스케줄러), 기본값(KT-Q1), 카톡용 문구 두 벌(T-6), 21~8시 금지.
- **KT-3 카카오톡 자료 받기:** 공유 대상 → 사건·서류 종류 → 지문 업로드 → 서류함·체크리스트.
- **KT-4 대화 내보내기 백업:** 원본 보관·지문·줄 해석(여러 형식)·중복 제외·보낸 사람 맞추기·백업 알림, 증빙 내보내기 포함.

**🟡 출시 직후**
- **KT-5 알림 읽기 보조 기록 (사무소 선택, 기본 끔).**
- **KT-7 카카오톡 공유 링크 카드:** 마이김변 카카오 앱 메시지 템플릿('서류 제출하기'·'제안서 보기'), 개인정보·금액 없음.
- 의뢰인 연락처 저장(KT-Q5 결정 시).

**⚪ 출시 후**
- **KT-6 사무소 카카오톡 채널 + 상담톡 연동** (딜러 선정·비용 확인 후, 원하는 사무소부터).
- 채널별 '안내 후 의뢰인 행동까지 걸린 시간' 통계.

**🟡 출시 직후 (KT-Q7 결정)**
- **KT-8 PC 카카오톡 묶음 발송 연결 (사무소 선택, 11장):** 1단계 = 마이김변 '카톡 발송 목록'을 사용자 엑셀 양식 칸 그대로(구분·채팅방 이름·보낼 메시지·텍스트값) 30줄씩 내보내기 → 사무장이 엑셀 매크로로 발송 → 발송결과(1/0) 칸이 채워진 파일을 다시 올리면 소통 기록에 '담당자 카톡(PC 묶음)'으로 기록. 2단계(⚪, 사용량 보고) = 마이김변 PC 발송 도우미(윈도 작은 프로그램)가 발송 대기 목록을 받아 같은 방식으로 보내고 결과를 바로 회신.

**만들지 않는 것:** 안드로이드 접근성 서비스로 카카오톡 조작(카카오 업데이트마다 깨짐), 카카오톡 저장 파일 해독(보안), 브랜드 메시지(광고), 마이김변 단일 채널로 여러 사무소 상담 받기(제34조).

## 10. 완료 기준

- 알림톡 단계에서 '담당자 카카오톡'을 고르면 담당자 업무폰에 할 일이 생기고, 공유로 보낸 뒤 '보냈어요'를 누르면 소통 기록에 내용·첨부 지문·담당자·시각이 남아요. 기한을 넘기면 알림톡이 자동으로 나가고 기록에 '자동 대체'가 표시돼요.
- 계약·기일·보정 기한·납부 단계는 기본값으로 알림톡 발송 결과가 남아요.
- 카카오톡에서 공유한 사진·PDF가 원본 그대로 사건 서류함에 들어가고 기기·서버 지문이 같아요.
- 같은 대화방 내보내기 파일을 두 번 올리면 새 줄만 추가되고, 원본 파일은 두 개 모두 보관돼요. 해석 못 한 줄 0건 유실(원문 보관).
- 카카오톡 문구 기본값에 광고성·금지 표현 0건, 21~8시 발송 할 일 0건.
- 앱 권한 목록에 접근성 서비스·다른 앱 위 그리기 없음, 연락처 쓰기·알림 접근은 사무소가 켰을 때만 요청.
- (KT-8) 내보낸 '카톡 발송 목록'을 사용자 엑셀 양식(v4.1.0)에 붙여 넣으면 그대로 발송되고, 결과 파일을 올리면 1인 줄은 '담당자 카톡(PC 묶음)'으로 기록, 0인 줄은 할 일로 남아요. '의뢰인 카톡 이름'이 없거나 이름이 겹치는 사건은 목록에 0건. 기능을 켜기 전에는 메뉴가 보이지 않아요.

## 11. 사용자 제공 프로그램 분석 — `카카오자동화/엑셀 카카오톡 문자보내기 자동화 양식 v4.1.0.xlsm`

매크로를 실행하지 않고 파일을 풀어 VBA 원문을 읽었어요(olevba).

### 11-1. 정체

- 오빠두엑셀이 배포한 양식이에요(완료 메시지 제목 '오빠두엑셀', 외부 연결이 제작자 PC의 `엑셀 공휴일 일정 자동화 달력 v1.4.xlsx`·`엑셀 일정표.xlsx`를 가리킴 — 쓰이지 않는 남은 연결).
- 시트 1개 `카톡문자발송`, VBA 모듈 `mod_Main`(발송 순서)·`mod_fx`(윈도 창 조작 함수). 파일을 열 때 자동 실행되는 코드는 없고(통합 문서 모듈 비어 있음), 인터넷 접속·파일 다운로드·외부 프로그램 실행 코드도 없어요. 악성 동작은 보이지 않아요.

### 11-2. 동작

| 항목 | 내용 |
|:---|:---|
| 입력 | 8~37행(최대 30줄): B 구분(친구/채팅/오픈채팅), C 채팅방 이름, D 보낼 메시지, E 텍스트값(그림 발송용), F 발송결과. C2 발송방법(문자/그림/둘 다), C4 '채팅 우선열기' |
| 대화방 열기 | PC 카카오톡 메인 창(클래스 `EVA_Window_Dblclk`)을 찾아 친구 목록(`ContactListView`)이나 채팅 목록(`ChatRoomListView`)의 검색칸에 이름을 넣고 엔터 → **검색 결과 첫 번째 대화방이 열림** |
| 확인 | 제목이 C열 이름과 **정확히 같은 창**을 5초 안에 찾으면 진행, 못 찾으면 실패(0) |
| 보내기 | 입력칸(`RichEdit50W`)에 글을 넣고 붙여넣기 후 엔터. 그림은 시트의 '이미지' 도형에 E열 글을 얹어 복사 → Ctrl+V → 엔터 |
| 결과 | F열 1(성공)/0(실패). '실패내역남기기'로 실패 줄만 남겨 다시 보내기 |
| 기술 | Windows API(`FindWindow`·`SendMessage`·`PostMessage`·`keybd_event`·`SetForegroundWindow`·클립보드) |

### 11-3. 법률 사무소에서 쓸 때 문제

1. **'성공'은 '보냈다'가 아니에요.** 글 보내기 함수는 항상 성공을 돌려줘요. 창을 찾고 엔터를 눌렀다는 뜻이고, 카카오톡이 실제로 보냈는지는 확인하지 않아요.
2. **받는 사람을 이름으로만 고르기 때문에 오발송 위험이 있어요.** 같은 이름의 친구가 둘이거나, 이미 같은 제목의 창이 열려 있으면 다른 사람에게 갈 수 있어요. 의뢰인 사건 안내라면 개인정보 유출이 돼요. 그래서 마이김변에서 쓸 땐 사건마다 등록한 '의뢰인 카톡 이름'만 쓰고, 이름이 겹치면 목록에서 빼요.
3. **글 입력이 ANSI 방식이에요.** 메시지를 `SendMessageA`(WM_SETTEXT)로 넣어서 한국어 윈도(CP949)의 한글은 되지만, 이모지나 CP949에 없는 글자는 '?'로 깨질 수 있어요. 그 뒤 클립보드를 비우고 붙여넣기를 한 번 하는데 빈 내용이라 효과는 없어요.
4. **발송 중 PC를 쓸 수 없어요.** 키보드 입력을 흉내 내서 창을 앞으로 가져오고 엔터를 누르기 때문에, 그동안 다른 작업을 하면 엉뚱한 창에 입력될 수 있어요.
5. **기록이 엑셀에만 남고 받은 답장은 모아 주지 않아요.** 백업·증빙은 4장 방식(대화 내보내기)이 따로 필요해요.
6. **카카오톡 PC 버전이 바뀌면 창 이름·구조가 바뀌어 멈출 수 있어요.**
7. 오빠두엑셀 배포물이라 코드를 마이김변에 복사해 넣지 않아요. 연결은 이 양식의 **칸 구조만 맞춰** 내보내고 결과를 받아요(KT-8 1단계). 2단계 PC 도우미는 새로 작성해요.

### 11-4. KT-8 1단계 흐름 (출시 직후 추천)

```
[마이김변] 알림톡 단계 '담당자 카카오톡' 할 일이 여러 건 쌓임 → '카톡 묶음 발송' 화면
  → 대상 고르기(의뢰인 카톡 이름 등록 + 이름 중복 없음만) → 30줄씩 엑셀 양식 칸 그대로 내보내기
[사무장 PC] 엑셀 양식에 붙여넣기 → 발송 → 발송결과 채워짐 → 그 파일(또는 B~F열 복사)을 마이김변에 올리기
[마이김변] 1인 줄 = '담당자 카톡(PC 묶음) 발송 처리', 0인 줄 = 할 일 유지 → 기한이 지나면 알림톡 자동 대체(KT-2)
```

- 켤 때 1회 안내 '[운영자 판단] PC 카카오톡 자동 조작은 카카오 공식 기능이 아니라 계정이 제한될 수 있고, 이름이 같은 친구에게 잘못 갈 수 있어요'. 사무소 설정에서 끄고 켜요.
- 발송 간격·하루 건수는 사무소 설정값(고정 상한 없음).
- 이 프로그램 폴더는 오빠두엑셀 배포물이라 커밋 대상에서 뺐어요(`.gitignore`에 `카카오자동화/`).
