## 0. 한눈에 보는 결론 (10-29 ST-Q1~Q6 추천안대로 결정으로 개편 방향 확정)

**설정 화면 10개 중 제대로 서버에 저장되고 실제로 쓰이는 것은 '내 프로필 편집'과 '보안·기기'의 세션 목록 두 가지뿐이에요.** 나머지는 이 브라우저에만 저장되거나, 저장은 되지만 아무 기능도 그 값을 읽지 않거나, 처음부터 가짜 값으로 채워져 있어요.

1. **스크린샷의 'AI 및 상담 스타일 프로필'은 아무 데서도 읽지 않아요.** 설명 분량·용어 수준·필수 고지·금지 표현·필수 안내 서류·링크 방식을 저장해도(브라우저 저장) 제안서·채팅·알림톡·AI 어디에도 반영되지 않아요. 화면 설명("금지 표현은 자동으로 걸러져요"류)이 사실과 달라요. 저장 버튼은 실패해도 늘 '저장 완료'예요.
2. **알림 연동은 처음부터 '연결됨'으로 보여요.** 텔레그램 연결 상태 기본값이 `true`, Chat ID 기본값이 `'12948592948'`이라 아무것도 설정하지 않아도 연결 카드가 켜져 있어요. 봇 토큰·Gmail 비밀번호는 탭 저장소(sessionStorage)라 브라우저를 닫으면 사라지고 '연결됨'만 남아 조용히 실패해요. 발송은 이 탭이 열려 있을 때만 브라우저에서 나가고, 텔레그램으로 지역·채무액·소득이 그대로 가요.
3. **사무소 이름이 네 군데에 따로 있어요.** 프로필 편집의 사무소명, 알림 화면의 '법인 명칭' 카드(같은 칸을 한 번 더 고침), 알림톡 설정의 사무소명, 광고·결제의 사업자 정보(브라우저 저장). 그런데 법원 서식·알림톡이 쓰는 `getOfficeProfile`은 광고·결제 사업자 정보를 읽어요. 프로필에서 고쳐도 서식에는 안 바뀌어요.
4. **직인·도장은 만들어도 문서에 찍히지 않아요.** 설정의 도장 스튜디오는 브라우저에만 저장하고 서버 프로필에 안 올려요(프로필 편집기를 거친 경우만 서버). 계약서 A4 미리보기는 '(법률사무소 직인)' 빈칸이고, '전자계약서 자동 날인'·'신청서 자동 날인' 토글을 읽는 곳이 없어요. 같은 기능의 모달이 두 개예요.
5. **'법률 기준' 화면은 통합어드민 기준을 보여 주지 않아요.** 통합어드민·변호사 둘 다 같은 패널을 쓰는데 저장 위치가 그 브라우저(`rehab_policy_settings`)라, 통합어드민이 고친 값은 관리자 브라우저에만 있어요. 서버 저장 함수(`loadRehabPolicySettings`·`saveRehabPolicySettings`)는 만들어 놓고 부르는 곳이 없어요. 변호사 화면은 코드 기본값(2026, 압류금지 185만 등 이미 틀린 값)을 보여 줘요.
6. **가짜·남은 것:** 텔레그램 시뮬레이터('선착순 오픈 배정'·'내가 즉시 담당자로 배정', LA-Q2 삭제 결정), 저장 안 되는 근무 시간·에스컬레이션, 'SaaS Enterprise 가동 중' 배지, 캘린더 홈페이지 링크일 뿐인 '외부 캘린더 동기화', 중복 '모든 기기에서 로그아웃' 카드, 이 브라우저 전체(사람 구분 없음) 알림 로그.
7. **구조:** 개인 설정(내 알림·내 프로필)과 사무소 설정(사무소 정보·발송 방법·보안 정책)이 섞여 있고, 직원 5개 역할 모두 설정 전체를 열 수 있어요(백업만 대표 전용).

**개편 방향:** 설정을 **'내 설정'(나만)**과 **'사무소 설정'(대표·권한 받은 사람)** 두 갈래로 나누고, 모든 값을 서버에 저장해요. 사무소 정보는 한 곳에서 고치고 서식·알림톡·계약·세금계산서가 모두 그 값을 읽어요. 아무도 읽지 않는 칸은 지우고, 남기는 칸은 실제 기능과 연결해요. 상담 스타일은 **'의뢰인 발송 문구 규칙'**으로 바꿔 발송 전 문구 검사기에 실제로 연결해요(경고 + 확인 + 기록, 막지 않음).

### 3-2. 서버 저장 (ST-2)

- `office_settings`: 사무소 × 구역(`profile`·`seal`·`client_messaging`·`copy_rules`·`fee`·`work_defaults`·`security`·`team_channels`) 한 행씩, `data jsonb`·`version`·`updated_by`·`updated_at`. 저장할 때 버전을 확인해 두 사람이 동시에 고치면 뒤 사람에게 알려요(덮어쓰기 방지).
- `user_preferences`: 사람 × 구역(`notifications`·`display`), 본인만 읽고 씀.
- RLS: `office_settings` 읽기 = 같은 사무소 직원, 쓰기 = `has_office_permission(office_id, 'office.settings.<구역>')`(RB-1). 관리자는 제로날리지 범위 밖이 아닌 값(사무소명 등)만 함수로 조회.
- 변경 기록: 바꿀 때마다 `office_audit_logs`(RB)에 구역·바뀐 칸 이름·이전/이후 요약(비밀값은 '변경됨'만).
- 저장 결과: 서버가 받은 뒤에만 '저장했어요', 실패하면 칸 아래 오류와 '다시 저장'. 브라우저 저장으로 조용히 대체하지 않아요(6-1 원칙).
- 비밀값(텔레그램 봇 토큰 등): 브라우저에 두지 않고 서버 함수가 암호화해 저장, 화면에는 '등록됨 · 끝 4자리'만.

### 3-3. 사무소 정보 하나로 (ST-3)

- `getOfficeProfile()`은 `office_settings.profile`만 읽어요. 광고·결제 사업자 정보(`loadLawyerBusinessInfo`, 브라우저)·알림톡 사무소명·'법인 명칭' 카드는 지우거나 이 값을 보여 주기만 해요.
- 세금계산서용 사업자 정보(AD-6 `office_billing_profiles`)는 같은 화면 '사업자 정보' 칸에서 고치고, 주문 때 서버가 그 시점 값을 복사해요(17 기획서 설계 그대로).
- 변호사 개인 프로필의 '사무소명'은 소속 사무소 정보를 보여 주고, 1인 사무소는 프로필에서 바로 고치면 사무소 정보가 바뀌게 해요.
- 빈 칸이 있으면 법원 서식·알림톡 미리보기에 '사무소 정보에서 ○○을 입력해 주세요'를 띄워요(가짜 기본값 '서울회생법원'·'02-0000-0000' 금지, 07·08 기획서와 같은 원칙).

### 3-4. 직인·서명 (ST-5)

- 저장: Supabase 비공개 저장소(`office-assets`, 사무소 단위 경로), DB에는 경로만. Data URL을 행·브라우저에 두지 않아요.
- 사무소 직인은 사무소 설정, 변호사 개인 도장·서명은 내 설정. 도장 스튜디오는 `SealStudioModal` 하나만 남기고 `LawyerSealManagerModal`은 지워요. 도장 질감 개선은 E-3.
- 자동 날인 토글은 실제 출력이 읽게 만들어요: 계약서 A4·PDF(계약 위저드), 법원 서식 글자 PDF(H-7), 변호사 검토 제안서 PDF(B-5e). 출력 쪽 연결이 끝나기 전에는 토글을 숨겨요.
- 찍을 때마다 `office_audit_logs`에 '어떤 문서에 누가 날인' 기록.

### 3-5. 상담 스타일 → '의뢰인 발송 문구 규칙' (ST-6)

지금 칸 6개 중 실제로 쓸 수 있는 것은 **필수 고지**와 **금지 표현**뿐이에요. 설명 분량·용어 수준·링크 방식은 그 값을 쓰는 생성 기능이 없고(제안서·안내문은 변호사가 직접 쓰거나 고정 문안), '필수 안내 서류 목록'은 서류 목록 템플릿(DP)이 할 일이에요.

- **남기는 것:**
  - 필수 고지 문구: 제안서·의견서 끝에 자동으로 붙는 사무소 고지(플랫폼 공통 고지 `Disclaimers.tsx`는 그대로, 사무소 문구는 그 아래 추가).
  - 사무소 추가 금지 표현: 플랫폼 공통 사전(M-9 `marketing-compliance.js`·`copy-lint.mjs` 규칙과 같은 사전, '100% 보장'·'전격 면책'·'무조건'·'탕감'·'전담'·'배정' 등)에 사무소가 단어를 더 넣음. 공통 사전 단어는 사무소가 뺄 수 없음.
- **검사기 연결:** 변호사가 의뢰인에게 보내는 글(제안서 소견·채팅·알림톡 자유 문구·안내문 문구함·공개 Q&A 답변·프로필 소개)을 보내기 전에 같은 검사기로 확인해요. 걸리면 해당 단어에 표시하고 "[운영자 판단] 광고 규정상 문제가 될 수 있는 표현이에요. 그래도 보낼까요?" 창 → 고쳐 보내기 / 그대로 보내기(사유 선택) → 기록. 사무소가 '엄격'으로 바꾸면 그대로 보내기가 막혀요(사용자 방침: 기본은 권고, 막지 않음).
- **삭제:** 설명 분량·용어 수준·링크 방식 칸, 'AI' 이름. 필수 안내 서류 목록은 DP 서류 템플릿으로 옮김.

### 3-6. 알림 (ST-7·ST-8)

- **발송 위치를 서버로:** 지금은 변호사 탭이 열려 있을 때 브라우저가 텔레그램·이메일을 보내요. 이벤트(새 상담 요청·채팅·기한 등)가 서버에 생길 때 서버 함수(G-1 예약 발송 작업과 같은 큐)가 각 사람의 `user_preferences.notifications`를 보고 보내요.
- **채널:** 앱 안 알림(종)·브라우저 푸시·업무폰 푸시(CL)·이메일은 사람마다. 텔레그램은 사무소 팀 채널(ST-Q3 결정: 사무소가 켤 때만, 기본 끔). 개인 알림의 기본 채널은 업무폰 푸시 + 이메일.
- **내용 최소화:** 외부 채널(텔레그램·이메일·푸시)에는 "새 상담 요청 1건 · 확인하기 링크"처럼 건수와 링크만. 가명·지역·채무액·소득·사건번호를 넣지 않아요. 텔레그램은 처리방침 위탁·국외 이전 목록에 추가(A-3).
- **연결 확인:** '연결됨'은 서버가 실제 테스트 메시지를 보내 성공했을 때만. 실패하면 카드에 '연결 끊김 · 마지막 성공 시각'. 가짜 기본값(`true`·Chat ID) 삭제.
- **이메일:** 사무소 Gmail 비밀번호를 받지 않고 마이김변 발송 서버(기존 `api/notify.js` 경로)로 보내요.
- **발송 기록:** 브라우저 공용 로그 대신 서버 `notification_deliveries`(사람·채널·이벤트 종류·성공/실패, 내용 없음), 설정 › 내 알림 받기 아래에 최근 30일.

### 3-7. 법률 기준표 (ST-12)

- 통합어드민의 기준 저장을 서버(`rehab_policy_settings` 테이블, 이미 있는 `saveRehabPolicySettings`)로 바꾸고, 변호사·고객 화면·챗봇·계산 엔진이 모두 서버 값을 읽게 해요(B-3 단일 엔진과 같이). 브라우저 사본은 캐시로만.
- 변호사 화면은 읽기 전용으로, 불러올 때 형식 변환을 저장하지 않아요. 적용 연도·시행일·근거(고시 번호)를 표에 표시하고 '2026' 고정 문구를 지워요.
- 테이블 RLS: 읽기 모두(공개 기준값), 쓰기 관리자만(`is_platform_admin()`).

### 3-8. 지우는 것 (ST-14)

텔레그램 시뮬레이터 전체(LA-Q2), 가짜 '테스트 알림'·두 번째 텔레그램 설정 블록·저장 안 되는 근무 시간/에스컬레이션, 'SaaS Enterprise 가동 중', 외부 캘린더 링크 카드(ST-Q5 결정: 삭제, 출시 직후 ICS), 알림 화면의 중복 전체 로그아웃 카드, '법인 명칭' 카드, `LawyerSealManagerModal`, 브라우저 공용 알림 로그, 옛 브랜드('[다시시작 CRM]'·'@restart_alarm_bot'), 프로필 편집기의 '전담'·'밀착 관리'·'최적 해결' 문구.

**순서:** RB-1 → ST-2 → ST-1 → ST-3(H-7·KT-2보다 먼저, 서식·알림톡이 읽는 원본) → ST-12(B-3과 함께) → ST-4·ST-11 → ST-6(M-9 사전과 함께) → ST-7·ST-8(G-1 뒤) → ST-5(H-7·계약 PDF와 함께) → ST-9·ST-10(각 트랙 편집기가 생길 때마다 입구 추가) → ST-13(G-2) → ST-14.

## 6. 완료 기준

- 설정의 모든 값이 서버에 저장되고, 다른 브라우저·기기로 로그인해도 같은 값이 보여요. 저장 실패는 화면에 보여요.
- 직원 계정으로 사무소 설정을 열면 권한 없는 구역은 읽기만 되거나 숨겨지고, 서버도 쓰기를 거절해요.
- 사무소 정보 한 곳에서 사무소명·주소를 바꾸면 법원 서식 미리보기·알림톡 미리보기·계약서·제안서에 같은 값이 나와요. 빈 칸은 가짜 기본값 대신 입력 안내가 나와요.
- 사무소 직인을 등록하고 자동 날인을 켜면 계약서 PDF·법원 서식 PDF·제안서 PDF에 찍히고, 찍은 기록이 남아요. 출력 연결 전에는 토글이 보이지 않아요.
- 제안서 소견에 '100% 보장'을 쓰면 보내기 전에 경고 창이 뜨고, 그대로 보내면 사유와 함께 기록돼요. 사무소가 엄격 모드면 보낼 수 없어요.
- 새 상담 요청이 오면 변호사 탭이 닫혀 있어도 각자 고른 채널로 알림이 가고, 외부 채널 내용에 가명·채무액·소득이 없어요. 연결 카드는 실제 테스트 성공 때만 '연결됨'이에요.
- 통합어드민이 법률 기준을 바꾸면 변호사 '법률 기준표'·고객 계산기·챗봇·변제계획 편집기가 모두 같은 값을 보여요. 변호사 화면에서 기준이 저장되지 않아요.
- 텔레그램 시뮬레이터·SaaS 배지·캘린더 링크 카드·중복 로그아웃·법인 명칭 카드·도장 모달 중복이 코드에서 사라지고, 공지는 종 알림·홈에서 서버 공지를 보여 줘요.
- 설정 화면에 이모지·10~11px 글자·44px 미만 버튼이 없고, 로딩 스켈레톤·오류 카드·빈 상태가 있어요.
