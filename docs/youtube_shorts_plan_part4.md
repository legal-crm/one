# 마이김변 쇼츠·릴스 Part 4 (EP37 ~ EP66)

Part 1~3(EP01~36)과 주제가 겹치지 않는 30편을 새로 만들었다. 이번 편부터 한 번 렌더링하면 두 가지 규격이 함께 나온다. 유튜브 쇼츠용 세로 영상과 인스타그램용 정사각 영상이다.

## 1. 기획 방향

- **주제를 고른 방법**
  - 기존 36편에서 다룬 주제는 제외했다.
    - 보증인, 보정권고, 압류, 세금, 긱워커, 직업 제한, 대환대출
    - 파산 요건, 수임료, 채권자집회, 편파변제, 새출발기금, 기각·폐지, 워크아웃
    - 금지명령, 신청 요건, 연체 전 신청, 담보, 부양가족, 월세 등
  - 그 대신 상담에서 자주 나오지만 아직 다루지 않은 질문을 골랐다.
    - 소멸시효, 지급명령, 상속, 불법 사금융
    - 비면책채권, 보증금·보험·퇴직금 같은 재산 평가
    - 명의 대여, 변호사 교체 등
- **근거**
  - 법 조항에 있는 수치와 요건만 쓴다.
    - 최고금리 연 20%, 지급명령 이의 2주, 면제재산 신청 14일 등
  - 연도별로 바뀌는 금액은 쓰지 않는다. 대신 "기준은 바뀔 수 있음"이라고 표기한다.
  - 영상 속 사연과 화면은 모두 "예시"로 표기한다.
- **검수**
  - `api/_lib/marketing-compliance.js`의 `scanCompliance()`로 30편 전체를 검사했다.
  - High와 Medium 등급 지적은 0건이다.
  - 법 조항 번호는 조문 원문과 대조했다.

## 3. 음성

edge-tts 한국어 신경망 음성 3종을 말투 프리셋 7개로 나눠 쓴다.

| 프리셋 | 음성 | 쓰는 곳 |
|---|---|---|
| sunhi / sunhi_bright / sunhi_soft | ko-KR-SunHiNeural | 기본 진행, 퀴즈 MC, 공감형 |
| injoon / injoon_deep | ko-KR-InJoonNeural | 해설, 브리핑 |
| hyunsu / hyunsu_up | ko-KR-HyunsuMultilingualNeural | 대화체, 경쾌한 카운트다운 |

- **두 사람 편**
  - 퀴즈, 톡, 인터뷰 편은 대사마다 화자를 지정해 두 사람 목소리로 진행한다.
  - 화자가 바뀔 때는 0.36초, 같은 화자가 이어 말할 때는 0.2초 간격을 둔다.
- **자막 싱크**
  - edge-tts의 WordBoundary 이벤트로 단어 단위 타이밍을 받는다.
  - 이 타이밍으로 카라오케 자막과 모션 싱크를 맞춘다.
- **음량 처리**
  - 화자 간 음량을 맞추고 75Hz 하이패스를 적용한다.
  - BGM은 내레이션이 나오는 구간에서 자동으로 낮춘다(더킹).
  - 최종 음량은 loudnorm으로 -14 LUFS에 맞춘다.
- **BGM**
  - 코드로 직접 합성한다. 스타일은 lofi, pluck, news, bright, warm, pad 6종이다.
  - 효과음도 직접 합성한다. 저작권 이슈가 없다.

## 6. 코드와 실행

| 파일 | 역할 |
|---|---|
| `scripts/shorts/p4_engine.py` | 레이아웃 2종, 테마, 텍스트 스프라이트, TTS와 단어 싱크, BGM 합성, 믹스, 인코딩 |
| `scripts/shorts/p4_kinds.py` | 포맷별 장면 렌더러 |
| `scripts/shorts/p4_ep_a.py` · `p4_ep_b.py` · `p4_ep_c.py` | 30편 대본 |
| `scripts/shorts/render_p4.py` | CLI, 병렬 렌더링, upload.txt·upload_reels.txt 생성 |

```powershell
python scripts/shorts/render_p4.py 37            # EP37 세로 + 정사각
python scripts/shorts/render_p4.py 37-46 -j 3     # 범위, 3개 병렬 (메모리 여유에 맞춰 조절)
python scripts/shorts/render_p4.py all -j 3       # 30편 전체
python scripts/shorts/render_p4.py 43 --preview   # 인코딩 없이 검수용 프레임만
python scripts/shorts/render_p4.py --export-text out.json   # 컴플라이언스 검사용 텍스트
```

- TTS 캐시는 `assets/shorts/_tts_cache/`에 저장된다. 이 폴더는 gitignore 대상이다.
- 대사를 고치면 바뀐 줄만 새로 합성한다.
